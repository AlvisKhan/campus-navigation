UNIT I

Introduction

10 topics
1.1

Biological Neuron

The biological blueprint every artificial neuron copies.

A biological neuron has four functional parts: dendrites collect incoming electrochemical signals from other neurons; the soma (cell body) integrates (sums) these signals; the axon carries the signal away once a firing threshold is crossed; and the synapse is the junction where the axon terminal meets the next neuron's dendrite, releasing neurotransmitters that either excite or inhibit the receiving neuron.

Two ideas from this biology carry straight into artificial neurons:

  • Weighted summation — synapses have different strengths, so not all inputs count equally.
  • All-or-none firing — a neuron only fires (sends a spike) once its integrated input crosses a threshold — the seed of the activation function.
Map it

Dendrites → inputs x₁…xₙ  |  Synaptic strength → weights w₁…wₙ  |  Soma summation → Σwᵢxᵢ + b  |  Firing threshold → activation function  |  Axon output → y

1.2

Idea of Computational Units

A neuron is just a small function.

A computational unit (artificial neuron) is a mathematical function that takes a vector of inputs, combines them, and produces an output. Every unit does two things, always in this order:

  1. Aggregation — compute a net input, usually a weighted sum: net = Σ wᵢxᵢ + b
  2. Activation — squash/transform the net input through a (usually nonlinear) function: y = f(net)
y = f( Σᵢ wᵢxᵢ + b )  // w: weights, b: bias, f: activation
Exam point

Stacking many computational units in layers, each feeding the next, is literally what "neural network" means — a network of these small functions. Everything in Unit II builds on this one equation.

1.3

McCulloch–Pitts Unit & Thresholding Logic

1943 — the first mathematical model of a neuron.

The McCulloch–Pitts (M-P) neuron takes binary inputs (0/1), and produces a binary output using a fixed threshold θ. Inputs can be excitatory (positive weight, encourages firing) or inhibitory (a single active inhibitory input forces the output to 0, regardless of everything else).

y = 1 if (Σ xᵢ ≥ θ) and no inhibitory input is active
y = 0 otherwise

With the right threshold θ, an M-P unit can implement basic logic gates:

GateInputsWeightsθ
ANDx₁, x₂1, 12
ORx₁, x₂1, 11
NOTx₁ (inhibitory)−10
Limitation

M-P units have fixed, hand-set weights and threshold — there is no learning rule. They also only accept binary inputs. This is exactly the gap the Perceptron closes.

1.4

Linear Perceptron

Rosenblatt, 1958 — the first neuron that could learn.

The perceptron generalizes the M-P unit: inputs and weights are now real-valued, and the weights (and bias) are learned from data instead of hand-set. It computes a weighted sum and passes it through a hard threshold (step / sign) activation.

net = w·x + b  =   w₁x₁+w₂x₂+⋯+wₙxₙ+b
y = 1 if net ≥ 0, else 0   // step activation

Geometrically, w·x + b = 0 is a hyperplane (a line in 2‑D) that splits the input space into the two output classes — the perceptron is a linear classifier.

1.5

Perceptron Learning Algorithm (PLA)

How the weights actually get learned.

For every training example (x, t) where t is the true label (0/1 or −1/+1), compare the predicted output y to the target t and nudge the weights toward reducing the error.

1  initialize w, b (often to 0 or small random values)
2  for each training sample (x, t):
    y = step(w·x + b)
    w ← w + η (t − y) x  // η = learning rate
    b ← b + η (t − y)
3  repeat step 2 over the dataset until no errors (or max epochs)

Only misclassified points cause an update — if t = y, (t−y)=0 and nothing changes. The rule pushes the hyperplane toward misclassified positive points and away from misclassified negative points.

Exam point

PLA update rule is often asked verbatim: w ← w + η(t−y)x. Know that it updates only on misclassification, and that η only scales step size — it doesn't affect whether convergence happens for linearly separable data.

1.6

Linear Separability

The one condition a perceptron truly needs.

A dataset with two classes is linearly separable if a single straight line (or hyperplane in higher dimensions) can separate all points of one class from all points of the other. AND and OR are linearly separable; XOR is not — no straight line can separate its 0s from its 1s.

Classic exam question

"Why can't a single perceptron learn XOR?" — because XOR's positive and negative classes cannot be separated by any single hyperplane. This is resolved by adding a hidden layer (Unit II, Multilayer Networks), which can combine multiple linear boundaries into a nonlinear one.

Try the Load XOR demo button in the Playground above — watch the perceptron keep oscillating and never converge, since no line can fit those four points.

1.7

Convergence Theorem for PLA

The guarantee behind the algorithm.

Theorem (statement)

If a training dataset is linearly separable, the Perceptron Learning Algorithm is guaranteed to find a separating hyperplane (zero training errors) in a finite number of updates, regardless of the initial weights.

A commonly quoted bound: if the data lies within a ball of radius R and there exists a separating hyperplane with margin γ (the smallest distance from any point to the boundary), then the number of mistakes the PLA makes is at most:

mistakes ≤ (R / γ)²
ConditionConsequence
Data is linearly separablePLA converges in finite steps
Data is not linearly separable (e.g. XOR)PLA never converges — weights oscillate forever
Larger margin γFewer updates needed to converge
Exam point

Remember two things word-for-word: (1) the theorem's condition is linear separability, and (2) its conclusion is convergence in a finite number of steps — it says nothing about speed or which particular separating hyperplane you'll end up with (there can be many).

"Feedforward" = no cycles, signal only moves forward. "Recurrent" = has at least one cycle, giving the network memory of previous states.

1.9

Activation Functions

Where the network gets its nonlinearity.

Without a nonlinear activation function, stacking layers would collapse into one big linear function (a multilayer network without nonlinearity is mathematically equivalent to a single-layer one). Activation functions introduce the nonlinearity that lets networks approximate complex functions.

Exam point

Backpropagation needs the activation function to be differentiable. That's precisely why step/sign (used in the classic perceptron) cannot be used inside a backprop-trained multilayer network — sigmoid, tanh, and ReLU are the practical choices.

1.10

Basic Learning Rules

Different recipes for updating weights.

RuleUpdateIdea
Hebbian ruleΔw = η·x·y"Neurons that fire together, wire together" — strengthen weight when input and output are both active
Perceptron ruleΔw = η(t−y)xUpdate only on misclassification (see PLA above)
Delta rule (Widrow–Hoff / LMS)Δw = η(t−y)xSame form as perceptron rule but derived from minimizing squared error via gradient descent — y here is the raw linear output, not thresholded, and works with continuous outputs
Correlation ruleΔw = η·xᵢtᵢSpecial case of Hebbian learning used for pattern association / associative memories
Competitive / winner-take-allonly the "winning" neuron updatesNeurons compete for the right to respond; used in unsupervised clustering nets
Don't mix these up

Perceptron rule and Delta rule look identical algebraically, but the Perceptron rule comes from a mistake-driven heuristic on a thresholded output, while the Delta rule is derived by taking the gradient of the squared-error cost with respect to weights — it's the direct ancestor of gradient descent and backpropagation in Unit II.

UNIT II

Feedforward Networks

2.1

Multilayer Neural Network

Stacking perceptrons to escape linear separability.

A Multilayer Perceptron (MLP) has an input layer, one or more hidden layers, and an output layer, with every neuron in one layer connected to every neuron in the next (fully connected / dense). Each hidden neuron computes f(w·x+b) with a nonlinear activation, and the outputs of one layer become the inputs of the next.

Because hidden layers combine multiple linear boundaries, an MLP can represent non‑linearly separable functions like XOR, and — per the Universal Approximation Theorem — a network with a single hidden layer of sufficient width can approximate any continuous function to arbitrary accuracy.

Exam point

Number of hidden layers/neurons is a design choice (hyperparameter), not something the training algorithm decides. More hidden units → more capacity → more risk of overfitting (see Regularization below).

2.2

Gradient Descent Learning

Rolling downhill on the error surface.

Define a cost/loss function J(w) measuring how wrong the network's predictions are (e.g. mean squared error). Gradient descent updates weights in the direction that decreases J fastest — the negative gradient.

w ← w − η ∇J(w)  // η = learning rate (step size)
VariantGradient computed overTrade-off
Batch GDentire training set per updateStable, accurate gradient; slow per update, needs lots of memory
Stochastic GD (SGD)one random sample per updateFast, noisy updates; noise can help escape local minima
Mini-batch GDsmall batch (e.g. 32–256) per updatePractical middle ground — most commonly used
Tip

Learning rate η is critical: too small → painfully slow convergence; too large → overshoots minima or diverges. It is the single most tuned hyperparameter in gradient-based learning.

2.3

Backpropagation

The chain rule, applied layer by layer.

Backpropagation is the algorithm that efficiently computes ∇J for every weight in a multilayer network, using the chain rule of calculus, so gradient descent can be applied. It has two passes:

  1. Forward pass — push an input through the network layer by layer, compute the output, and the loss J against the true target.
  2. Backward pass — starting from the output layer, propagate the error backward, computing ∂J/∂w for each weight via the chain rule, then update every weight with gradient descent.
Output layer: δᵒ = (y − t) · f′(netᵒ)
Hidden layer: δʰ = (Σₖ δᵒₖ wₖ) · f′(netʰ)  // error passed backward through weights
Weight update: Δwᵢⱼ = −η · δⱼ · xᵢ
Exam point (frequently asked derivation)

Be ready to derive δ for a single hidden unit using the chain rule: error at output → multiplied by the output activation's derivative → propagated back through the connecting weight → multiplied by the hidden unit's own activation derivative. This "local gradient × derivative × weight" pattern repeats for every layer going backward — that's the essence of the algorithm.

2.4

Empirical Risk Minimization (ERM)

Why we minimize training error at all.

The true risk is the expected loss over the entire (unknown) data distribution — what we actually care about. Since we can't access that distribution directly, we minimize the empirical risk: the average loss over the finite training set we do have.

True risk: R(f) = E(x,y)~D[ L(f(x), y) ]  // unknown, can't compute directly
Empirical risk: R̂(f) = (1/N) Σᵢ L(f(xᵢ), yᵢ)  // computable over N training samples

ERM is the principle of choosing the model f that minimizes R̂(f). Backpropagation + gradient descent is precisely the machinery used to carry out ERM for neural networks.

The catch

Minimizing empirical risk too aggressively causes overfitting — the model memorizes training data (low training error) but fails to generalize to new data (high true risk). This gap is why regularization exists.

2.5

Regularization

Keeping the model honest about generalizing.

MethodMechanismFormula / idea
L2 (weight decay)Penalizes large weights, encourages small, spread-out weightsJ' = J + λΣwᵢ²
L1Penalizes absolute weight magnitude, encourages sparsity (many weights → 0)J' = J + λΣ|wᵢ|
DropoutRandomly "drops" (zeroes) a fraction of neurons during each training stepforces redundancy, prevents co-adaptation
Early stoppingStop training once validation error starts rising, even if training error keeps fallingdirectly targets the overfitting point
J'(w) = J(w) + λ·R(w)  // λ = regularization strength, R(w) = penalty term
Tip

λ trades off bias and variance: λ=0 gives plain ERM (risk of overfitting/high variance); very large λ forces weights toward 0 (risk of underfitting/high bias). Tuning λ on a validation set is standard exam-and-practice knowledge.

2.6

Radial Basis Function Neural Network

Local "bumps" instead of global lines.

An RBF network has three layers: an input layer, a single hidden layer of radial basis (Gaussian) neurons, and a linear output layer. Each hidden neuron measures how close the input is to its own "center" cⱼ, using a radially symmetric function — typically a Gaussian:

φⱼ(x) = exp( −‖x − cⱼ‖² / 2σⱼ² )
y = Σⱼ wⱼ φⱼ(x)  // output layer is just a weighted sum

Training an RBF network is typically done in two stages:

  1. Unsupervised — choose the centers cⱼ (e.g. via k-means clustering on the input data) and widths σⱼ.
  2. Supervised — with centers fixed, the output layer weights wⱼ are learned by a simple linear method (e.g. least squares / gradient descent), since the output is linear in these weights.
MLPRBF Network
Hidden activationGlobal (sigmoid/tanh/ReLU span the whole input space)Local (Gaussian activates only near its center)
Decision boundaryFormed from combinations of hyperplanesFormed from combinations of localized "bumps"
TrainingEnd-to-end backpropagationTwo-stage: unsupervised centers + supervised output weights
Typical layersMany hidden layers possibleExactly one hidden layer
Exam point

The key contrast question is almost guaranteed: "Differentiate MLP and RBF network." Anchor your answer on global vs. local activation and the single-stage vs. two-stage training difference shown above.

Likely Exam Questions & Model Answers

Why can't a single-layer perceptron solve the XOR problem?
XOR's positive class {(0,1),(1,0)} and negative class {(0,0),(1,1)} cannot be separated by any single straight line — XOR is not linearly separable. A perceptron computes one hyperplane decision boundary, so it structurally cannot represent XOR. This is solved by adding a hidden layer (MLP), where two hyperplanes can be combined nonlinearly.
State and explain the Perceptron Convergence Theorem.
If a dataset is linearly separable, the Perceptron Learning Algorithm is guaranteed to converge — i.e., find a set of weights that correctly classifies every training point — in a finite number of updates, for any initial weights and any (fixed, positive) learning rate. If the data is not linearly separable, the algorithm never converges. A common bound on the number of mistakes is (R/γ)², where R is the radius bounding the data and γ is the margin of the best separating hyperplane.
Differentiate between the Perceptron learning rule and the Delta (LMS) rule.
Both have the algebraic form w ← w + η(t−y)x, but they come from different derivations. The Perceptron rule is a mistake-driven heuristic applied to a thresholded (step-function) output — it only makes sense for binary classification and has no defined gradient. The Delta rule is derived by taking the gradient of the mean-squared-error cost function with respect to the weights (i.e., it is gradient descent on a continuous, linear output) — it generalizes naturally to continuous outputs and is the direct precursor to backpropagation.
Explain the forward and backward pass in backpropagation.
Forward pass: an input is propagated through the network layer by layer using y = f(w·x+b) at each neuron, producing a final output that is compared to the target using a loss function J. Backward pass: starting at the output layer, the error signal δ is computed (δᵒ = (y−t)f′(net)); this is propagated backward through the weights to every hidden layer (δʰ = (Σ δᵒw)f′(net)) using the chain rule; then every weight is updated via gradient descent, Δw = −η·δ·x. This lets a single pass compute exact gradients for every weight in the network in time proportional to the network size.
What is Empirical Risk Minimization, and how does it relate to overfitting?
True risk is the expected loss over the true (unknown) data distribution. Since it can't be computed directly, ERM instead minimizes the empirical risk — the average loss over the available training samples — as a proxy. When a model is complex enough to fit training data very closely, empirical risk can be driven near zero while true risk (performance on unseen data) stays high; this gap is overfitting. Regularization narrows this gap by discouraging the model from fitting noise in the training set.
Compare L1 and L2 regularization.
Both add a penalty term λ·R(w) to the loss to discourage large weights. L2 (weight decay) penalizes the sum of squared weights (λΣwᵢ²), which shrinks weights smoothly toward — but rarely exactly to — zero, spreading influence across many weights. L1 penalizes the sum of absolute weights (λΣ|wᵢ|), which tends to push many weights to exactly zero, producing sparse models useful for implicit feature selection.
Differentiate an MLP from an RBF Network.
An MLP uses global activation functions (sigmoid/tanh/ReLU) at each hidden unit — a single hidden unit's response spans the whole input space — and is trained end-to-end with backpropagation, potentially across many hidden layers. An RBF network uses local Gaussian activation functions where a hidden unit responds strongly only near its own center, has exactly one hidden layer, and is typically trained in two stages: centers/widths chosen by an unsupervised method (e.g. k-means), then output weights fit by a simple supervised (often linear) method.
Why must the activation function be differentiable for backpropagation to work?
Backpropagation computes weight gradients via the chain rule, which requires taking f′(net) at every neuron. A non-differentiable function like the step/sign activation has a derivative of 0 almost everywhere (and is undefined at the threshold), so the chain rule would give exactly zero gradient signal — no learning could occur. Sigmoid, tanh, and ReLU (differentiable, or sub-differentiable at one point) all provide a useful gradient almost everywhere.
