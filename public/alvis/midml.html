Introduction to Machine Learning

Tom Mitchell's Formal Definition of Learning:

A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E.

E = Experience (historical data, past games) T = Task (playing checkers, spam detection) P = Performance (% games won, classification accuracy)

Why Machine Learning?

1. No Readily Available Algorithm Infeasible Logic

Problems where rules cannot be specified easily in code.

Examples Spam detection Face recognition
2. Inexplicable Human Expertise Tacit Knowledge

Humans excel at the task but cannot formulate the internal logic.

Examples Speech recognition Medical diagnosis
3. Dynamic Environments Non-Stationary

The underlying environment or trends continuously evolve over time.

Examples Stock market forecasting Fraud detection
4. Hyper-Personalization User Adaptation

Systems that require custom-tailored behavior for individual users.

Examples Content recommenders Personalized feeds
When NOT to use ML: Standard deterministic problems with well-defined algorithmic logic (e.g., sorting numbers, searching binary trees) do not need machine learning.

Conventional Programming vs Machine Learning

Conventional Programming
[Data] + [Program] ➔ [Output]

Human software engineer writes deterministic rules (program) to transform input data into results.

Machine Learning
[Data] + [Output] ➔ [Program]

Machine learning algorithm extracts patterns and discovers the program from observed data and answers.

The Three Learning Paradigms

Family Sub-Types Typical Tasks / Algorithms
Supervised Classification (categorical label)
Regression (continuous quantity)		 Decision Trees, SVM, k-NN, Naive Bayes, Linear/Logistic Regression
Unsupervised Clustering (grouping similar points)

Reinforcement Reward-based Learning (agent & environment) Q-Learning, Policy Gradients, Deep Q-Networks

Classification: A Two-Step Process

1
Model Construction (Training Phase)

Build the classifier using a training set where class labels are known. The learning algorithm extracts patterns mapping attributes to target classes.

2
Model Usage (Testing & Inference Phase)

Estimate the model's accuracy on an independent test set where labels are held out. If accuracy is acceptable, deploy the model to classify previously unseen real-world instances.

Overfitting Warning: The test set must remain completely independent of the training set. Evaluating accuracy on the training data provides a dangerously over-optimistic estimate.

Data Quality & Outlier Detection

Why Preprocessing is Critical:

Real-world data is dirty: noisy (errors/outliers), incomplete (missing values), and inconsistent (duplicate codes or discrepancies). "No quality data, no quality results."

Data Quality Dimensions

Accuracy Completeness Consistency Timeliness Believability Interpretability Accessibility

Major Preprocessing Tasks

1. Data Cleaning

Fill missing values, smooth noisy data, identify and remove outliers, resolve inconsistencies.

2. Data Integration

Combine multiple databases, files, or tables into a unified store.

3. Data Transformation

Normalization and aggregation to scale features into comparable intervals.

4. Data Reduction

Obtain reduced representation that produces identical analytical outcomes.

5. Discretization

Convert continuous numeric attributes into categorical interval bins.

Outlier Detection Methods

Method 1: Box Plot Analysis (Interquartile Range - IQR)

IQR = Q3 − Q1 Upper Whisker (UW) = Q3 + 1.5 × IQR Lower Whisker (LW) = Q1 − 1.5 × IQR Outlier Criterion: Value < LW or Value > UW

Normal Distribution Justification (Why 1.5 × IQR?):
For a normal distribution $X \sim \mathcal{N}(\mu, \sigma^2)$, the quartiles correspond to $z_{0.25} = -0.6745$ and $z_{0.75} = +0.6745$.
Hence, $\text{IQR} = 2 \times 0.6745\sigma \approx 1.349\sigma$.
The upper cutoff is: $Q3 + 1.5 \times \text{IQR} \approx 0.6745\sigma + 1.5(1.349\sigma) \approx \mathbf{2.68\sigma}$. Observations beyond $\pm 2.68\sigma$ represent extreme tail outliers (only 0.7% of normal data).

Method 2: Z-Score Standard Score Method

Z_i = (x_i − μ) / σ where σ = √( Σ(x_i − μ)² / (n − 1) ) Standard Cutoff: |Z_i| > 2 or |Z_i| > 3

Slide Example: Given mean $\mu = 5.956$ and sample standard deviation $\sigma = 3.016$, testing value $x = 13.2$: $$Z = \frac{13.2 - 5.956}{3.016} = \mathbf{2.40}$$ Since $2.40 > 2.0$, it is flagged as an outlier at the $\pm 2\sigma$ threshold (retained at $\pm 3\sigma$).

2 marks

Missing Data & Imputation

Root Causes of Missing Data

1. Sensor & Equipment Malfunction

Hardware failures, dead batteries, or transmission drops causing null readouts.

2. Manual Deletion (Inconsistency)

Data deleted by administrators because recorded values contradicted verified facts.

3. Value Omission During Entry

Human subject skipped survey questions, or clerk missed data entry fields.

4. Deemed Unimportant at Collection

Field was not tracked initially and only became necessary at a later date.

Imputation Strategies

MethodMechanismKey Advantage / Disadvantage
Ignore the Tuple Drop the entire row from the dataset. Essential when the class label is missing. Wasteful if feature missingness is low.
Manual Fill Human operator manually investigates and inputs value. Accurate but extremely slow, expensive, and infeasible on large datasets.
Global Constant Replace with "Unknown", "Missing", or $\infty$. Simple, but the algorithm might mistake the constant for an actual predictive class.
Attribute Mean / Median Replace with mean (symmetric data) or median (skewed data). Preserves overall mean, but deflates overall variance.
Attribute Mode Replace with the most frequently occurring categorical value. Standard approach for qualitative nominal/ordinal features.
Class-Wise Mean / Mode Calculate mean or mode only among samples belonging to the same class. Significantly smarter and preserves class-conditional distribution.
k-NN Imputation Find $k$ nearest rows based on known features; take average or mode of their values. Uses multi-attribute correlations; sensitive to feature scaling and distance metric.
Professor's Slide Rules for Data Preparation:
  • Rule 1: Drop any instance/row containing more than 50% missing values.
  • Rule 2: Remove columns (e.g. PAN Number, Student ID) that have zero predictive correlation with the target.
  • Rule 3: Impute numerical continuous attributes using mean or median (or class-wise mean).
  • Rule 4: Impute categorical features using the mode.
  • Rule 5: If the class label is missing, ALWAYS ignore/drop that tuple.

Noise, Smoothing & Discretization

Noise is random error or variance in a measured variable. Primary smoothing techniques include Binning, Regression, and Clustering.

Binning Smoothing Worked Example

Sorted Price Data: 4, 8, 15, 21, 21, 24, 25, 28, 34 (Partitioned into 3 equal-frequency bins):

Bin 1: [4, 8, 15] Bin 2: [21, 21, 24] Bin 3: [25, 28, 34] Smoothing by Bin Means: Bin 1: (4+8+15)/3 = 9 ➔ [9, 9, 9] Bin 2: (21+21+24)/3 = 22 ➔ [22, 22, 22] Bin 3: (25+28+34)/3 = 29 ➔ [29, 29, 29] Smoothing by Bin Medians: Bin 1: median = 8 ➔ [8, 8, 8] Bin 2: median = 21 ➔ [21, 21, 21] Bin 3: median = 28 ➔ [28, 28, 28] Smoothing by Bin Boundaries: Bin 1: min=4, max=15 ➔ 4 ➔ 4, 8 ➔ 4 (closer to 4), 15 ➔ 15 ➔ [4, 4, 15] Bin 2: min=21, max=24 ➔ 21 ➔ 21, 21 ➔ 21, 24 ➔ 24 ➔ [21, 21, 24] Bin 3: min=25, max=34 ➔ 25 ➔ 25, 28 ➔ 25 (closer to 25), 34 ➔ 34➔ [25, 25, 34]

Discretization: Equal-Width vs Equal-Frequency

Data: 5, 10, 11, 13, 15, 35, 50, 55, 72, 89, 204, 215 ($N=12$, $k=3$ bins):

Equal-Width Binning Unsupervised

Divides range into $k$ intervals of equal size: $W = \frac{\text{Max} - \text{Min}}{k} = \frac{215 - 5}{3} = 70$.

Bin 1 [5, 75]: 5, 10, 11, 13, 15, 35, 50, 55, 72 (9 values)
Bin 2 (75, 145]: 89 (1 value)
Bin 3 (145, 215]: 204, 215 (2 values)
Drawback: Heavily skewed by extreme outliers.
Equal-Frequency (Equal-Depth) Unsupervised

Divides range so each bin contains approximately equal sample count: $\frac{N}{k} = \frac{12}{3} = 4$ per bin.

Bin 1: 5, 10, 11, 13 (4 values) ➔ Label 1
Bin 2: 15, 35, 50, 55 (4 values) ➔ Label 2
Bin 3: 72, 89, 204, 215 (4 values) ➔ Label 3
Advantage: Outliers are naturally grouped without skewing.

Normalization (Data Transformation)

Scales attribute ranges so that large-magnitude features do not dominate distance calculations in k-NN, SVM, and Neural Networks.

Min-Max Normalization
v' = (v − min_A) / (max_A − min_A) × (new_max − new_min) + new_min

Preserves exact linear relationships. Maps values into a fixed interval (e.g. $[0, 1]$ or $[-1, 1]$).

Z-Score Normalization
v' = (v − μ_A) / σ_A

Centres distribution at 0 with unit variance. Robust when min and max are unknown or outliers exist.

Decimal Scaling
v' = v / 10^j where j = smallest integer such that max|v'| < 1

Normalizes by shifting the decimal point according to maximum absolute value.

Worked Examples from Slides:

1. Scale $F_1 = [5, 32]$: Normalize $v = 16$ to $[0, 1]$:
$$v' = \frac{16 - 5}{32 - 5} = \frac{11}{27} \approx \mathbf{0.407}$$

2. Scale to $[-5, 5]$:
$$v' = 0.407 \times (5 - (-5)) + (-5) = 4.074 - 5 = \mathbf{-0.926}$$

3. Decimal Scaling for range $[-917, 986]$:
$\text{Max}|v| = 986$. Smallest power of 10 exceeding 986 is $10^3 = 1000$ ($j=3$).
Divide all values by 1000: $-917 \rightarrow \mathbf{-0.917}$, $986 \rightarrow \mathbf{+0.986}$.

Decision Tree Induction

Decision Tree Components

• Root Node: Holds the entire dataset, tested on the single best split attribute.
• Internal Nodes: Feature evaluation tests.
• Branches: Specific attribute outcomes.
• Leaf Nodes: Terminal nodes holding class labels.

Core Impurity Metrics

Entropy(D) = − Σ_{i=1}^m p_i log₂ p_i (Pure node = 0, 50/50 split = 1.0) Gini(D) = 1 − Σ_{i=1}^m p_i² (Pure node = 0, 50/50 split = 0.5) Error(D) = 1 − max_i(p_i) (Pure node = 0, 50/50 split = 0.5)

7.1 ID3 Algorithm (Information Gain)

Info(D) = − Σ p_i log₂ p_i Info_A(D) = Σ_{j=1}^v (|D_j| / |D|) · Info(D_j) Gain(A) = Info(D) − Info_A(D) ➔ Select attribute with HIGHEST Gain(A)
Slide Example (Where = Home 3 / Work 3):

Total dataset entropy $ ext{Info}(D) = 1.0$. Partition entropies: $ ext{Info}_{ ext{Action}} = 1.000$, $ ext{Info}_{ ext{Author}} = (4/6)(0.811) + (2/6)(0) = 0.540$, $ ext{Info}_{ ext{Thread}} = 0.918$, $ ext{Info}_{ ext{Length}} = 1.000$.

Gains: $ ext{Gain}( ext{Action}) = 0$, $mathbf{ ext{Gain}( ext{Author}) = 0.460}$, $ ext{Gain}( ext{Thread}) = 0.082$, $ ext{Gain}( ext{Length}) = 0$. ➔ Author is selected as the Root.

7.2 Limitation of Information Gain & C4.5 (Gain Ratio)

The Flaw of Information Gain: ID3 is heavily biased towards features with many distinct values (e.g. Roll Number or Transaction ID). Splitting on unique IDs creates pure partitions with $ ext{Info}_A(D) = 0$ and $ ext{Gain} = 1.0$, but the model merely memorizes the data and fails completely on unseen instances.
SplitInfo_A(D) = − Σ_{j=1}^v (|D_j| / |D|) log₂ (|D_j| / |D|) GainRatio(A) = Gain(A) / SplitInfo_A(D) ➔ Select HIGHEST GainRatio(A)
QAnalyse Gain(A) = Info(D) − Info_A(D), show the necessity of split information with an example, and derive the ratio of information gain.
10 marks

1. Meaning of Information Gain: $\text{Gain}(A)$ measures the expected reduction in entropy (uncertainty) achieved by partitioning dataset $D$ using feature $A$.

2. Failure Mode (Why Split Information is Necessary):
Suppose a class has 6 students with attribute Roll_No (values 1 to 6). Splitting on Roll_No yields 6 pure singleton subsets ($|D_j| = 1$), each having entropy 0. Thus $\text{Info}_{\text{Roll}}(D) = 0$, giving $\text{Gain}(\text{Roll}) = 1.0$, identical to a truly predictive attribute like Study_Hours.

3. Split Information Penalty:

SplitInfo(Roll) = − 6 × (1/6) log₂(1/6) = log₂(6) ≈ 2.585 SplitInfo(Study) = − 2 × (1/2) log₂(1/2) = 1.000 GainRatio(Roll) = 1.0 / 2.585 = 0.387 GainRatio(Study) = 1.0 / 1.000 = 1.000

Conclusion: $\text{GainRatio}$ penalizes fragmented splits and selects Study_Hours over Roll_No.

7.3 CART (Classification and Regression Trees)

CART uses strictly binary splits (two child nodes per decision) and optimizes Gini Impurity.

Gini(D) = 1 − Σ p_k² Gini_split(A) = (|D_L| / |D|) · Gini(D_L) + (|D_R| / |D|) · Gini(D_R) ΔGini(A) = Gini(D) − Gini_split(A) ➔ Best split: MIN Gini_split or MAX ΔGini Continuous Features: Evaluate midpoints of sorted unique values.
Slide Example (Age: 22, 25, 28, 35, 40, 45; Buy: N, N, Y, Y, Y, Y):

Total dataset $ ext{Gini}(D) = 1 - (4/6)^2 - (2/6)^2 = 0.4444$. Candidate midpoint thresholds: 23.5, 26.5, 31.5, 37.5, 42.5 produce $ ext{Gini}_{ ext{split}} = 0.400, 0.347, 0.222, mathbf{0.1667}, 0.200$.

Best Split: $ ext{Age} le 37.5$, yielding $Delta ext{Gini} = 0.2777$.

Support Vector Machines (SVM)

Fundamental Principle of SVM:

Among all possible separating hyperplanes, SVM selects the unique hyperplane that maximizes the geometric margin ($m = rac{2}{|w|}$). The position is governed solely by Support Vectors.

Primal & Dual Formulations

Hyperplane: wᵀx + b = 0 Margin: m = 2 / ‖w‖ Constraints: y_i (wᵀx_i + b) ≥ 1, y_i ∈ {+1, −1} Primal Problem: Minimise ½ ‖w‖² = ½ wᵀw subject to y_i(wᵀx_i + b) ≥ 1 ∀i Dual Problem: Maximise W(α) = Σ_{i=1}^n α_i − ½ Σ_i Σ_j α_i α_j y_i y_j (x_iᵀ x_j) subject to Σ α_i y_i = 0 and α_i ≥ 0
QDerive the dual optimization of the hard-margin SVM.
5 marks
1
Formulate Lagrangian Function

Introduce Lagrange multipliers $\alpha_i \ge 0$: $$L(w, b, \alpha) = \frac{1}{2} w^T w + \sum_{i=1}^n \alpha_i \Big(1 - y_i(w^T x_i + b)\Big)$$

2
Set Gradients to Zero (Stationarity)

$$\frac{\partial L}{\partial w} = w - \sum_{i=1}^n \alpha_i y_i x_i = 0 \implies \mathbf{w = \sum_{i=1}^n \alpha_i y_i x_i}$$ $$\frac{\partial L}{\partial b} = -\sum_{i=1}^n \alpha_i y_i = 0 \implies \mathbf{\sum_{i=1}^n \alpha_i y_i = 0}$$

3
Substitute Back to Obtain Dual

The linear $b$-term vanishes because $\sum \alpha_i y_i = 0$. The resulting Dual Problem depends only on inner products $x_i^T x_j$: $$\max_\alpha W(\alpha) = \sum_{i=1}^n \alpha_i - \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \alpha_i \alpha_j y_i y_j (x_i^T x_j)$$ $$\text{subject to } \sum_{i=1}^n \alpha_i y_i = 0 \quad \text{and} \quad \alpha_i \ge 0$$

QExplain how SVM handles linearly inseparable cases, with an example.
2 marks

SVM handles inseparability in two ways:

  • 1. Soft Margin: Adds slack variables $\xi_i \ge 0$ allowing margin violations, tuned by penalty parameter $C$.
  • 2. Kernel Trick: Projects low-dimensional inseparable data into higher-dimensional space where linear separation exists.

Example: 1-D data $x = 1, 2, 6$ ($+1$) and $4, 5$ ($-1$) cannot be linearly split. Using polynomial kernel $K(a, x) = (ax + 1)^2$ transforms them into a parabola $f(x) = 0.667x^2 - 5.333x + 8 = 0$, completely separating the classes.

k-Nearest Neighbour (k-NN)

Three Defining Properties of k-NN:
Lazy Learner: No training model built Instance-Based: Classifies by comparing against stored points Non-Parametric: Assumes no functional form for $P(X)$

5-Step Execution Workflow

1
Compute Distance

Calculate geometric distance from query point $x_{\text{test}}$ to every training point in $D$.

2
Sort Distances

Sort computed distances in ascending order.

3
Select $k$ Neighbours

Extract top $k$ rows closest to the query point.

4
Read Labels

Retrieve ground-truth target class labels of these $k$ instances.

5
Aggregate Voting

Take majority vote (for classification) or arithmetic mean (for regression).

Distance Metrics

Euclidean (L2 Norm)
d(x, y) = √( Σ_{i=1}^n (x_i − y_i)² )

Straight-line shortest distance between two points.

Manhattan (L1 Norm)
d(x, y) = Σ_{i=1}^n |x_i − y_i|

Sum of absolute axis-aligned differences.

Minkowski Distance
d(x, y) = ( Σ |x_i − y_i|^p )^(1/p)

Generalized metric: $p=1$ (Manhattan), $p=2$ (Euclidean).

Choosing $k$ & The Elbow Method

Heuristic Rules

Rule of thumb: $k \approx \sqrt{n}$. Always use an odd $k$ in binary classification to prevent voting ties.

Cross-Validation

Test range $k = 1 \dots 30$; pick the value of $k$ that minimizes validation error.

Naive Bayes Classifier

Bayes' Theorem & Conditional Independence:
P(C | X) = [ P(X | C) · P(C) ] / P(X) Posterior = (Likelihood × Prior) / Evidence Class Decision: Ĉ = argmax_{C} P(C) · Π_{i=1}^n P(x_i | C)
QPredict Stolen for X = (Red, SUV, Domestic) from the 10-row vehicle table (5 Yes, 5 No).
Slide Example

Priors: $P(\text{Yes}) = 5/10 = 0.5$, $P(\text{No}) = 5/10 = 0.5$.

Conditionals:

  • For Yes: $P(\text{Red}|\text{Yes}) = 3/5 = 0.6$, $P(\text{SUV}|\text{Yes}) = 1/5 = 0.2$, $P(\text{Domestic}|\text{Yes}) = 2/5 = 0.4$
  • For No: $P(\text{Red}|\text{No}) = 2/5 = 0.4$, $P(\text{SUV}|\text{No}) = 2/5 = 0.4$, $P(\text{Domestic}|\text{No}) = 3/5 = 0.6$
P(Yes | X) ∝ 0.5 × 0.6 × 0.2 × 0.4 = 0.024 P(No | X) ∝ 0.5 × 0.4 × 0.4 × 0.6 = 0.048 Prediction: P(No|X) > P(Yes|X) ➔ PREDICT NOT STOLEN

Zero-Probability Problem & Laplace Smoothing

Zero-Probability Trap: If an attribute combination has zero training occurrences ($P(x_i|C) = 0$), multiplying causes the entire product to become zero, discarding all other strong evidence.

Laplace Correction Formula:

P(x_i | C) = (n_{x_i, C} + 1) / (N_C + k) where: n_{x_i, C} = count of samples in class C with value x_i N_C = total samples in class C k = number of distinct categorical values for feature A
QProblem 2 (7 rows): X = (Red, Sports, Imported). Solve, show the zero-frequency problem and fix it with Laplace smoothing.
2.5+2.5 marks

Priors: $P(\text{Yes}) = 4/7$, $P(\text{No}) = 3/7$.

Without Laplace: P(Yes | X) ∝ (4/7) × (3/4)(3/4)(1/4) = 0.0804 P(No | X) ∝ (3/7) × (0/3)(1/3)(2/3) = 0 ← P(Red|No) = 0 wipes out class No! With Laplace Correction (k = 2 values per attribute): P(Red|No) = (0 + 1) / (3 + 2) = 1/5 P(Sports|No) = (1 + 1) / (3 + 2) = 2/5 P(Imported|No) = (2 + 1) / (3 + 2) = 3/5 P(No | X) ∝ (3/7) × (1/5) × (2/5) × (3/5) = 0.0206 P(Yes | X) smoothed: (4/7) × (4/6)(4/6)(2/6) = 0.0847 Since 0.0847 > 0.0206 ➔ PREDICT YES (and class No is not wiped out)

Top 6 Mistakes to Avoid in the Exam Hall:
  1. Forgetting Prior $P(C)$ in Naive Bayes: Do not calculate only likelihood products; multiply by the class prior!
  2. Using Population $sigma$ instead of Sample $sigma$: Always divide by $n - 1$ when computing sample standard deviation.
  3. Base of Logarithms: Information theory uses $log_2$, not natural $ln$ or $log_{10}$. ($log_2(x) = rac{ln(x)}{ln(2)}$).
  4. Missing Class Labels: If a row has a missing class label, drop the row. Never impute the target label for model training!
  5. CART Branching: Never make multiway splits in CART; CART is strictly binary.
  6. Skipping Derivation Steps: In SVM dual derivations, explicitly write down the Lagrangian stationarity conditions $ rac{partial L}{partial w} = 0$ and $ rac{partial L}{partial b} = 0$.
