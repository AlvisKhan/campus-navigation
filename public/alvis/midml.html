1. Introduction

Tom Mitchell: a program learns from experience E with respect to tasks T and performance measure P if its performance at T, measured by P, improves with E. Finding that logic is "machine learning".
Why ML?

Use it when:

• No algorithm is readily available

Example spam detection

• No human experts exist

• Experts cannot explain their expertise

Example speech recognition

• The environment changes

Example share market

• Personalisation is needed

Note: Sorting numbers needs no ML.

Conventional programming:
Data + Program → Output
Machine Learning:
Data + Output → Program
FamilyTypes
SupervisedClassification (categorical label), Regression (continuous value)
UnsupervisedClustering, Association

Classification is a two-step process:

(1) Model construction on a training set with known class labels.

(2) Model usage: estimate accuracy on an independent test set, then classify new data.

The test set must be independent of training, otherwise you get overfitting.

"No quality data, no quality results."

Outlier: a data point that differs significantly from other observations; it lies far from the overall pattern.
Typical problems:
• noise and outliers
• missing values
• duplicates (e.g. age 300, negative expense)

3.1 Box plot analysis

IQR = Q3 − Q1 Upper whisker = Q3 + 1.5 × IQR Lower whisker = Q1 − 1.5 × IQR Outside the whiskers = potential outlier

Box plot shows min, Q1, median (Q2), Q3, max; the box spans the middle 50% (IQR).

Slide example (4.3, 4.5, 4.5, 4.5, 4.7, 4.7, 4.7, 8.5, 13.2): Q1 = 4.5, Q3 = 6.6, IQR = 2.1, UW = 9.75, LW = 1.35, so 13.2 is an outlier.

Why 1.5 × IQR?

For X ~ N(μ, σ²): z0.25 = −0.6745, z0.75 = +0.6745, so Q1 ≈ μ − 0.6745σ, Q3 ≈ μ + 0.6745σ, IQR ≈ 1.349σ.

Then 1.5·IQR ≈ 2.02σ and UW ≈ 0.6745σ + 2.02σ = 2.68σ. Points beyond ±2.68σ are outliers.

3.2 Z-score analysis

Z_i = (x_i − μ)/σ σ = √( Σ(x_i − μ)² / (n − 1) )

Pick a threshold (±1, ±2 or ±3). Slide example: μ = 5.956, σ = 3.016; for 13.2, Z = (13.2 − 5.956)/3.016 = 2.40. Outlier at ±2σ, but no outliers at ±3σ.

6. Normalization (data transformation)

Scales an attribute into a small range so that no attribute dominates because of a larger range. Essential for distance-based methods (nearest neighbour, clustering) and neural networks.

Min-max: v' = (v − min_A)/(max_A − min_A) × (new_max − new_min) + new_min Z-score: v' = (v − μ_A)/σ_A (useful when min and max are unknown) Decimal: v' = v / 10^j j = smallest integer with max|v'| < 1
Slide examples:
• F1 = 5…32 to [0,1]: 16 → (16−5)/(32−5) = 0.407
• To [−5,5]: 16 → 0.407 × 10 − 5 = −0.925
• Decimal scaling of 4.3…13.2: max = 13.2, j = 2, so 4.3 → 0.043 and 13.2 → 0.132
• A range 917 to 986 → divide by 1000
Normalize Blood Pressure to [−0.5, +0.5]. Compare with z-score. 2 marks

min = 32, max = 296. v' = (v − 32)/264 × (0.5 − (−0.5)) + (−0.5). So 32 → −0.5, 296 → +0.5, 72 → −0.348, 66 → −0.386, 40 → −0.470. The outlier 296 squeezes normal values into about [−0.5, −0.3].

7. Decision tree induction

A tree where:

• Each internal (decision) node tests a feature
• Each branch is an outcome
• Each leaf gives a class label
• Root = whole dataset split by the best feature
• Pruning removes branches to reduce overfitting

Best splits come from impurity measures:

Gini = 1 − Σ p_i² Entropy = − Σ p_i log₂ p_i Error = 1 − max(p_i)

Entropy measures impurity. Pure node = 0. 50/50 split = 1 (maximum). The minus sign keeps entropy ≥ 0 because log₂ p < 0. Slide: 16 green + 14 pink of 30 → Info(D) = 0.99.

7.2 Limitation of information gain and Gain Ratio (C4.5)

Gain is biased towards attributes with many distinct values. Slide: splitting on Roll No. (unique for every student) gives every subset entropy 0, so Gain = 1.0, equal to Study Hours, but it is useless on new data (pure overfitting). Fix:

SplitInfo(A) = − Σ_j (|D_j|/|D|) log₂(|D_j|/|D|) GainRatio(A) = Gain(A) / SplitInfo(A) → choose the highest

Many unique values give a high SplitInfo, which penalises the attribute; balanced partitions are favoured.

Slide result: Gain(Author) = 0.459, SplitInfo = 0.918, GainRatio = 0.500; Thread 0.0817/1 = 0.0817; Action and Length = 0. Root = Author.

Analyse Gain(A) = Info(D) − Info_A(D), show the necessity of split information with an example, and derive the ratio of information gain. 10 marks

Gain is the reduction in uncertainty after splitting on A: Info(D) is the uncertainty before, InfoA(D) the weighted uncertainty after.

Problem: an ID-like attribute splits D into |D| singleton subsets, each pure, so InfoA(D) = 0 and Gain is maximal (6 students: Gain(Roll) = 1.0 = Gain(Study Hours)), yet it cannot generalise.

Split information measures how broadly and evenly A partitions the data: SplitInfo(Roll) = −6·(1/6)log₂(1/6) = 2.585, while SplitInfo(Study) = −2·(1/2)log₂(1/2) = 1. So GainRatio(Roll) = 1/2.585 = 0.387 < GainRatio(Study) = 1/1 = 1.0, and Study Hours is correctly chosen.

Derivation: normalise Gain by SplitInfo(A) = −Σ(|D_j|/|D|)log₂(|D_j|/|D|), giving GainRatio(A) = Gain(A)/SplitInfo(A).

Classification And Regression Trees: recursive binary partitioning, so every internal node has exactly two branches. Classification uses Gini impurity (leaf = majority class); regression uses MSE/SSE (leaf = mean).

Gini(D) = 1 − Σ p_k² p_k = n_k / N Gini_split = (|D_L|/|D|)·Gini(D_L) + (|D_R|/|D|)·Gini(D_R) ΔGini = Gini(D) − Gini_split Best split = argmin Gini_split = argmax ΔGini Continuous X_j: D_L = {X_j ≤ t}, D_R = {X_j > t}; t = midpoints of sorted values

8. Support Vector Machines (SVM)

SVM comes from statistical learning theory (Vapnik and Chervonenkis). It can represent non-linear functions and has an efficient training algorithm. It gave a 1.1% error rate on handwritten digits, comparable to a carefully built ANN.

Key idea: many lines separate two linearly separable classes, so choose the boundary as far from both classes as possible: maximise the margin m. Support vectors are the points the margin pushes against.
Hyperplane: wᵀx + b = 0 margins: wᵀx + b ≥ +1 and wᵀx + b ≤ −1 Margin m = 2/√(w·w) = 2/‖w‖ Labels y_i ∈ {+1, −1} constraint: y_i(wᵀx_i + b) ≥ 1 ∀i

Primal (hard margin): maximising 2/‖w‖ is the same as

Minimise ½‖w‖² = ½ wᵀw subject to y_i(wᵀx_i + b) ≥ 1
Derive the dual optimization of the hard-margin SVM. 5 marks

Step 1: Lagrangian with multipliers α_i ≥ 0 for constraints 1 − y_i(wᵀx_i + b) ≤ 0:

L = ½ wᵀw + Σ α_i (1 − y_i(wᵀx_i + b))

Step 2: set gradients to zero.

∂L/∂w = w − Σ α_i y_i x_i = 0 ⇒ w = Σ α_i y_i x_i ∂L/∂b = −Σ α_i y_i = 0 ⇒ Σ α_i y_i = 0, α_i ≥ 0

Step 3: substitute w back into L. The b-term vanishes because Σα_i y_i = 0, and wᵀw = Σ_i Σ_j α_i α_j y_i y_j (x_iᵀx_j):

max_α W(α) = Σ α_i − ½ Σ_i Σ_j α_i α_j y_i y_j (x_iᵀ x_j) subject to Σ α_i y_i = 0, α_i ≥ 0

This is the dual problem. It depends only on the dot products x_iᵀx_j, which enables kernels. Points with α_i > 0 are the support vectors. Then w = Σ α_i y_i x_i and b = −½( min_{y_i=+1} w·x_i + max_{y_i=−1} w·x_i ).

Worked example: find the maximum-margin hyperplane for (2,2) → −1, (4,5) → +1, (7,4) → +1. slide example

Dot products: x₁·x₁ = 8, x₁·x₂ = 18, x₁·x₃ = 22, x₂·x₂ = 41, x₂·x₃ = 48, x₃·x₃ = 65. Constraint: −α₁ + α₂ + α₃ = 0, so α₁ = α₂ + α₃.

W = (α₁+α₂+α₃) − ½(8α₁² + 41α₂² + 65α₃² − 36α₁α₂ − 44α₁α₃ + 96α₂α₃) Substitute α₁: W = 2(α₂+α₃) − ½(13α₂² + 32α₂α₃ + 29α₃²) ∂W/∂α₂ = 2 − 13α₂ − 16α₃ = 0 ∂W/∂α₃ = 2 − 16α₂ − 29α₃ = 0 α₂ = 26/121, α₃ = −6/121, α₁ = 20/121 w = Σ α_i y_i x_i = (2/11, 6/11) b = −½( min(w·x₂, w·x₃) + max(w·x₁) ) = −½(38/11 + 16/11) = −27/11 f(x) = (2/11)x₁ + (6/11)x₂ − 27/11 = 0 ⇔ x₁ + 3x₂ − 13.5 = 0

Check: w·x₂ + b = 38/11 − 27/11 = 1 ✓ and w·x₁ + b = 16/11 − 27/11 = −1 ✓.

Strictly, α₃ = −6/121 breaks α ≥ 0, so the true optimum has α₃ = 0 (x₃ is not a support vector). In the exam, follow your professor's steps above and mention this only if asked.

Centroids: x₊ = (1.5, 1), x₋ = (0.5, 1); their average (1, 1) lies on 2x₁ + x₂ − 3 = 0 (2 + 1 − 3 = 0 ✓). Classify a new point by the sign of f(x) = wᵀx + b.

Linearly inseparable data: soft margin (slack variables)

y_i(wᵀx_i + b) ≥ 1 − ξ_i, ξ_i ≥ 0 Minimise ½‖w‖² + C Σ ξ_i ξ_i = 0: correct, on/outside margin 0 < ξ_i ≤ 1: inside margin, still correct ξ_i > 1: misclassified
C smallC large
Weak penalty, wider margin, more violations, possible underfittingStrong penalty, narrower margin, fits training data closely, possible overfitting

Soft-margin dual: max Σα_i − ½ΣΣ α_iα_j y_i y_j x_iᵀx_j subject to 0 ≤ α_i ≤ C and Σα_i y_i = 0. The bound comes from ∂L/∂ξ_i = C − α_i − μ_i = 0 with μ_i ≥ 0. If ξ_i > 0 then μ_i = 0 and α_i = C; if ξ_i = 0 then α_i < C.

Non-linear SVM and the kernel trick

Map inputs with Φ: Rⁿ → H (higher-dimensional space) where the data becomes linearly separable; a linear boundary in H is non-linear in input space. The dual only needs dot products, so use a kernel K(x_i, x_j) = Φ(x_i)·Φ(x_j) without computing Φ explicitly.

Polynomial: K(x_i,x_j) = (x_i·x_j + c)^d Gaussian RBF: K(x_i,x_j) = exp(−γ‖x_i − x_j‖²) Sigmoid: K(x_i,x_j) = tanh(κ(x_i·x_j) + θ) Decision function: f(x) = Σ_{i=1..Ns} α_i y_i K(x_i, x) + b Bias from a support vector x_k on the margin: b = y_k − Σ α_i y_i K(x_i, x_k)
Slide example (1-D: x = 1, 2, 6 → +1; 4, 5 → −1; kernel K(a,x) = (ax + 1)²): α = (0, 2.5, 0, 7.333, 4.833), support vectors x = 2, 4, 5. b = 1 − [2.5(25) − 7.333(121) + 4.833(169)] = 8. f(x) = 0.6667x² − 5.333x + 8. Predict: f > 0 → class +1, f < 0 → class −1, f = 0 → on the boundary.
Explain how SVM handles linearly inseparable cases, with an example. 2 marks

Two ways.

(1) Soft margin: add slack variables ξi ≥ 0 so points may violate the margin: minimise ½‖w‖² + CΣξi subject to yi(wᵀxi + b) ≥ 1 − ξi; C trades margin width against errors.

(2) Kernel trick: map to a higher-dimensional space where the data is separable.

Example: 1-D points 1, 2, 6 (+1) and 4, 5 (−1) cannot be split by one threshold, but with the polynomial kernel (ax + 1)² the discriminant f(x) = 0.667x² − 5.333x + 8 separates them.

9. k-Nearest Neighbour (k-NN)

k-NN is a lazy, instance-based, non-parametric learner. It stores the whole training set and computes only when a test instance arrives: find the k closest training points and take a majority vote (classification) or the average (regression).
Algorithm:
(1) compute the distance from xtest to every xi in D
(2) sort ascending
(3) pick the k nearest
(4) read their class labels
(5) majority vote gives ytest
Euclidean (L2): d(x,y) = √( Σ (x_i − y_i)² ) Manhattan (L1): d(x,y) = Σ |x_i − y_i| Minkowski: d(x,y) = ( Σ |x_i − y_i|^p )^(1/p) p = 1 Manhattan, p = 2 Euclidean
Training:

just store data (very fast).

Prediction:

computationally heavy, because distances to all training samples are needed.

Storage:

high.

Choosing k

• Rule of thumb: k ≈ √n (n = training samples).
• Use an odd k for binary classification to avoid ties.
• Cross-validation: split into training and validation (e.g. 5-fold), try k = 1…30, pick the k with maximum validation accuracy (or minimum error).
• Elbow method: plot error rate vs k and pick the point where the curve flattens.
• Very large k biases towards the majority class.
• Normalize features first (distance-based method).

10. Naive Bayes classifier

A probabilistic classifier based on Bayes' theorem. It assumes features are conditionally independent given the class. It is an eager learner: it builds a model of priors and conditional probabilities.

P(C|X) = P(X|C) P(C) / P(X) posterior = likelihood × prior / evidence X = (x₁,…,x_n): P(X|C) = P(x₁|C)·P(x₂|C)·…·P(x_n|C) Ĉ = argmax_C P(C) Π_{i=1..n} P(x_i|C) (P(X) is constant, so ignored)
Predict Stolen for X = (Red, SUV, Domestic) from the 10-row vehicle table (5 Yes, 5 No). slide example

Step 1, priors: P(Yes) = 5/10 = 0.5, P(No) = 0.5.
Step 2, conditionals: Yes: P(Red|Yes) = 3/5 = 0.6, P(SUV|Yes) = 1/5 = 0.2, P(Domestic|Yes) = 2/5 = 0.4. No: P(Red|No) = 2/5 = 0.4, P(SUV|No) = 2/5 = 0.4, P(Domestic|No) = 3/5 = 0.6.

P(Yes|X) ∝ 0.5 × 0.6 × 0.2 × 0.4 = 0.024 P(No|X) ∝ 0.5 × 0.4 × 0.4 × 0.6 = 0.048 → predicted class: Not stolen

Zero-probability problem and Laplace smoothing

If a value never occurs with a class, e.g. P(Red|No) = 0, then P(X|No) = 0 wipes out the whole product. It only means the combination was not observed, not that it is impossible. Laplace smoothing: add 1 to each count.

P(x_i|C) = (n_{x_i,C} + 1) / (N_C + k) k = number of distinct values of that attribute
Problem 2 (7 rows): X = (Red, Sports, Imported). Solve, show the zero-frequency problem and fix it with Laplace smoothing. 2.5+2.5 marks

Data: Yes rows = (Red,Sports,Dom), (Red,Sports,Dom), (Red,SUV,Dom), (Yellow,Sports,Imp); No rows = (Yellow,Sports,Dom), (Yellow,SUV,Imp), (Yellow,SUV,Imp). P(Yes) = 4/7, P(No) = 3/7.

Yes: 4/7 × (3/4)(3/4)(1/4) = 4/7 × 0.1406 = 0.0804 No : 3/7 × (0/3)(1/3)(2/3) = 0 ← P(Red|No) = 0

Here the answer is still Yes, but the zero kills the No class completely, so any other evidence is ignored.

Laplace (each attribute has k = 2 distinct values here):
P(Red|No) = (0+1)/(3+2) = 1/5, P(Sports|No) = (1+1)/5 = 2/5, P(Imported|No) = (2+1)/5 = 3/5, giving No: 3/7 × 1/5 × 2/5 × 3/5 = 0.0206.
Yes (smoothed): 4/7 × (4/6)(4/6)(2/6) = 0.0847.
Yes > No, so predict Yes, and the No class is no longer zero.

Continuous attributes (not in your slides, so check if taught): use Gaussian P(x|C) = (1/(√(2π)σ_C)) exp(−(x−μ_C)²/(2σ_C²)) with μ_C, σ_C computed per class; or discretize first (Section 5) and then use counts.

Why is k-NN lazy and Naive Bayes not? 2 marks

k-NN does no training: it stores the entire dataset and at prediction time computes the distance from the test instance to every training instance, sorts them, and takes a majority vote of the k nearest. It is instance-based and non-parametric.

Naive Bayes computes priors P(C) and conditionals P(xi|C) during training, builds a model, and uses only those probabilities to predict, so it is an eager learner.
