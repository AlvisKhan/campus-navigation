Chapter 01 / Stack

Stack — LIFO Discipline

The most elegant data structure. Last thing in, first thing out — like a stack of plates.

01.01 — Concept

What is a Stack?

A Stack is a linear data structure that follows the LIFO (Last In, First Out) principle. Think of it as a pile of books — you always add or remove from the top. You can never take from the middle or bottom without removing everything above it first.

Key Insight
Only the top of the stack is accessible at any time. This restriction is what makes stacks powerful — they enforce order by design.
📚
Real-world analogy

Stack of plates

You put a plate on top. You take a plate from the top. You never pull from the middle. The last plate you placed is the first you'll pick up.

↩️
Classic Example

Browser History

Every page you visit is pushed onto a stack. When you click Back, the current page is popped off, revealing the previous one.

⚙️
CS Core

Function Call Stack

Your CPU uses a stack for function calls. When foo() calls bar(), bar is pushed. When bar() returns, it's popped and foo() resumes.

01.02 — Operations

Core Stack Operations

Operation STL Method What it does Time
push(x) s.push(x) Add element x to the top O(1)
pop() s.pop() Remove the top element (no return value!) O(1)
top() s.top() Access the top element without removing O(1)
empty() s.empty() Returns true if stack is empty O(1)
size() s.size() Returns number of elements O(1)
⚠️ Common Mistake
pop() in C++ STL does NOT return the value — it just removes it. Always call top() first to get the value, then pop() to remove it.
01.03 — Implementation

Stack in C++ — Three Ways

C++ · STL Stack
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> s;

    // push: add to top
    s.push(10);
    s.push(20);
    s.push(30);
    // Stack: bottom [10, 20, 30] top

    cout << "Top: " << s.top() << endl; // 30
    cout << "Size: " << s.size() << endl; // 3

    // ALWAYS check before pop!
    if (!s.empty()) {
        int val = s.top(); // get value FIRST
        s.pop();            // then remove
        cout << "Popped: " << val << endl; // 30
    }

    // Drain the stack
    while (!s.empty()) {
        cout << s.top() << " ";
        s.pop();
    }
    // Output: 20 10
    return 0;
}
C++ · Array Implementation
#include <iostream>
using namespace std;

class Stack {
    int arr[1000];
    int topIdx = -1;  // -1 means empty

public:
    void push(int x) {
        if (topIdx == 999) { cout << "Stack Overflow!\n"; return; }
        arr[++topIdx] = x;
    }

    void pop() {
        if (empty()) { cout << "Stack Underflow!\n"; return; }
        topIdx--;
    }

    int top() { return arr[topIdx]; }

    bool empty() { return topIdx == -1; }

    int size() { return topIdx + 1; }
};

int main() {
    Stack s;
    s.push(5); s.push(10); s.push(15);
    cout << s.top() << endl; // 15
    s.pop();
    cout << s.top() << endl; // 10
}
C++ · Linked List Implementation
#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;
    Node(int val) : data(val), next(nullptr) {}
};

class Stack {
    Node* topNode = nullptr;
    int sz = 0;

public:
    void push(int x) {
        Node* newNode = new Node(x);
        newNode->next = topNode;  // point to old top
        topNode = newNode;        // update top
        sz++;
    }

    void pop() {
        if (empty()) return;
        Node* tmp = topNode;
        topNode = topNode->next;
        delete tmp;  // free memory!
        sz--;
    }

    int top() { return topNode->data; }
    bool empty() { return topNode == nullptr; }
    int size() { return sz; }
};

Chapter 02 / Queue

Queue — FIFO Discipline

Fair by design. The first one in is the first one served — just like a real-world line.

02.01 — Concept

What is a Queue?

A Queue is a linear data structure that follows the FIFO (First In, First Out) principle. Elements are added at the rear (back) and removed from the front. Think of a checkout line at a supermarket — the first person who joined the line is the first to be served.

Key Insight
A queue has two access points: the front (for removal) and the rear (for insertion). This ensures fairness — elements are processed in the exact order they arrived.
🏦
Real-world analogy

Bank Queue

People join at the back. The cashier serves from the front. Nobody can cut the line — this is FIFO.

🖨️
Classic Example

Print Spooler

Documents sent to a printer queue up and are printed in the order they were sent.

🌐
CS Core

BFS Graph Traversal

Breadth-First Search uses a queue to explore nodes level by level — an essential algorithm for shortest paths.

02.02 — Operations

Core Queue Operations

Operation STL Method What it does Time
enqueue / push q.push(x) Add element x to the rear O(1)
dequeue / pop q.pop() Remove element from the front O(1)
front() q.front() Access the front element (no removal) O(1)
back() q.back() Access the rear element (no removal) O(1)
empty() q.empty() Returns true if queue is empty O(1)
size() q.size() Returns number of elements O(1)
💡 Bonus: deque and priority_queue
C++ also offers deque<T> (double-ended queue — push/pop from both ends) and priority_queue<T> (max-heap by default — largest element always at top). Mastering all three makes you unstoppable.
02.03 — Implementation

Queue in C++ — Three Ways

C++ · STL Queue
#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;

    // push: enqueue at rear
    q.push(1);
    q.push(2);
    q.push(3);
    // Queue: front [1, 2, 3] rear

    cout << "Front: " << q.front() << endl; // 1
    cout << "Back:  " << q.back()  << endl; // 3

    // pop: dequeue from front
    q.pop();
    cout << "After pop, front: " << q.front() << endl; // 2

    // Drain the queue
    while (!q.empty()) {
        cout << q.front() << " ";
        q.pop();
    }
    // Output: 2 3
    return 0;
}
C++ · Circular Array Queue
// Circular array avoids wasted space after dequeue!
class CircularQueue {
    int arr[1000];
    int front = 0, rear = 0, sz = 0;
    const int CAP = 1000;

public:
    void push(int x) {
        if (sz == CAP) { cout << "Full!\n"; return; }
        arr[rear] = x;
        rear = (rear + 1) % CAP;  // wrap around!
        sz++;
    }

    void pop() {
        if (empty()) { cout << "Empty!\n"; return; }
        front = (front + 1) % CAP;  // wrap around!
        sz--;
    }

    int  front_val() { return arr[front]; }
    bool empty()     { return sz == 0; }
    int  size()      { return sz; }
};

// Why circular? A naive array wastes space after pop().
// Circular array reuses dequeued slots by wrapping rear and
// front with modulo — space-efficient O(1) operations!
C++ · deque & priority_queue
#include <deque>
#include <queue>

// ── deque: double-ended queue ──────────────────────────
deque<int> dq;
dq.push_back(10);   // add rear
dq.push_front(5);   // add front  → [5, 10]
dq.pop_front();      // remove front → [10]
dq.pop_back();       // remove rear  → []
// Key use: sliding window maximum!

// ── priority_queue (MAX heap by default) ──────────────
priority_queue<int> pq;
pq.push(3); pq.push(1); pq.push(7); pq.push(2);
cout << pq.top(); // 7 (always the maximum!)

// ── MIN heap: negate values or use comparator ─────────
priority_queue<int, vector<int>, greater<int>> minHeap;
minHeap.push(3); minHeap.push(1); minHeap.push(7);
cout << minHeap.top(); // 1 (minimum!)
// Use for: Dijkstra, K smallest/largest elements, merge K sorted

04.01 — Stack Pattern

Balanced Parentheses — The Classic

Given a string of brackets, determine if it's valid. This is the #1 stack interview problem. Every bracket that opens must be closed in the correct order.

Scan left to right

Iterate through each character in the string one by one.

Push opening brackets

If char is (, [, or { — push it onto the stack.

Pop and match closing brackets

If char is a closing bracket, check if stack is non-empty and top matches. If not → invalid!

Final check

After scanning, if the stack is empty → valid. Non-empty means unclosed brackets → invalid.

C++ · Balanced Parentheses
#include <stack>
#include <string>
using namespace std;

bool isValid(string s) {
    stack<char> st;

    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);  // push opener
        } else {
            // closing bracket — must match top
            if (st.empty()) return false;
            char top = st.top(); st.pop();
            if (c == ')' && top != '(') return false;
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
        }
    }
    return st.empty(); // valid only if no unclosed brackets
}

// isValid("({[]})") → true
// isValid("([)]")   → false
// isValid("{[]")    → false
04.02 — Stack Pattern

Next Greater Element — Monotonic Stack

For each element, find the next element to its right that is greater. Brute force is O(n²). Monotonic stack solves it in O(n).

Core Idea
Maintain a stack that is always decreasing from bottom to top. When a larger element arrives, it becomes the "next greater" for everything smaller that's been waiting on the stack.
C++ · Next Greater Element — O(n)
#include <vector>
#include <stack>
using namespace std;

vector<int> nextGreater(vector<int>& nums) {
    int n = nums.size();
    vector<int> result(n, -1); // default: no greater element
    stack<int> st; // stores indices

    for (int i = 0; i < n; i++) {
        // pop while current element is greater than stack top
        while (!st.empty() && nums[i] > nums[st.top()]) {
            result[st.top()] = nums[i]; // found next greater!
            st.pop();
        }
        st.push(i);
    }
    // remaining in stack have no next greater → stay -1
    return result;
}

// Input:  [2, 1, 5, 3, 6]
// Output: [5, 5, 6, 6, -1]
// Trace:
//   i=0: push 0.  stack=[0]
//   i=1: push 1.  stack=[0,1]
//   i=2: nums[2]=5 > nums[1]=1 → result[1]=5, pop
//         nums[2]=5 > nums[0]=2 → result[0]=5, pop
//         push 2.  stack=[2]
//   i=3: 3 < 5, push 3.  stack=[2,3]
//   i=4: nums[4]=6 > nums[3]=3 → result[3]=6, pop
//         nums[4]=6 > nums[2]=5 → result[2]=6, pop
//         push 4.  stack=[4]
04.03 — Queue Pattern

BFS — Level Order Traversal

Breadth-First Search is the definitive queue algorithm. Use it for shortest paths in unweighted graphs, level-by-level tree traversal, and reachability problems.

C++ · BFS — Binary Tree Level Order
#include <queue>
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> result;
    if (!root) return result;

    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        int levelSize = q.size(); // nodes at current level
        vector<int> level;

        for (int i = 0; i < levelSize; i++) {
            TreeNode* node = q.front(); q.pop();
            level.push_back(node->val);

            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
        result.push_back(level);
    }
    return result;
}
// Key pattern: snapshot levelSize BEFORE the inner loop
// This separates one level from the next!
04.04 — Tricky Pattern

Implement Queue using Two Stacks

A classic interview question that tests your deep understanding of both structures. The trick: two reversals cancel out — a stack reverses order; reversing twice restores FIFO.

C++ · Queue using 2 Stacks (Amortized O(1))
#include <stack>
using namespace std;

class MyQueue {
    stack<int> inbox;   // for push
    stack<int> outbox;  // for pop/front

    void transfer() {
        // move all from inbox → outbox (reverses order)
        if (outbox.empty()) {
            while (!inbox.empty()) {
                outbox.push(inbox.top());
                inbox.pop();
            }
        }
    }

public:
    void push(int x) {
        inbox.push(x); // always push to inbox
    }

    int pop() {
        transfer();           // lazy transfer
        int val = outbox.top();
        outbox.pop();
        return val;
    }

    int front() {
        transfer();
        return outbox.top();
    }

    bool empty() {
        return inbox.empty() && outbox.empty();
    }
};

// Why amortized O(1)?
// Each element is pushed once (O(1)) and
// transferred at most once (O(1)).
// Across N operations: total work = O(N) → avg O(1) per op.
Bonus: Implement Stack using Two Queues
The reverse problem: use two queues to mimic a stack. Push to queue2, then move everything from queue1 to queue2, then swap. Push is O(n), pop is O(1).
04.05 — Advanced Pattern

Min Stack — O(1) getMin()

Design a stack that supports push, pop, top, and retrieving the minimum element in constant time. The trick: maintain a parallel stack tracking minimums.

C++ · Min Stack
class MinStack {
    stack<int> main_s;  // normal stack
    stack<int> min_s;   // tracks minimums

public:
    void push(int val) {
        main_s.push(val);
        // push to min_s if it's the new minimum (or min_s empty)
        if (min_s.empty() || val <= min_s.top()) {
            min_s.push(val);
        }
    }

    void pop() {
        if (main_s.top() == min_s.top()) {
            min_s.pop(); // remove from min_s only if it was minimum
        }
        main_s.pop();
    }

    int top()    { return main_s.top(); }
    int getMin() { return min_s.top(); } // O(1)!
};

// push(5), push(3), push(7), push(2)
// main_s: [5, 3, 7, 2]
// min_s:  [5, 3,    2]  ← only new minimums tracked
// getMin() → 2 in O(1)!

🎯 Golden Rules to Never Forget
1. Always check empty() before calling top() / front() / pop() — calling on empty = undefined behaviour.
2. STL pop() does NOT return a value — call top()/front() first!
3. Monotonic stack → maintain sorted order → solve NGE, histogram, trapping rain water.
4. BFS = Queue. DFS = Stack (explicit or call stack).
5. deque = both push_front/back + pop_front/back — perfect for sliding window problems.
