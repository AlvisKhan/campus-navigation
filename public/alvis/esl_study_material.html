Chapter 01

Introduction

The nature of learning from data, and real-world examples that motivate the field.

Statistical learning is the science of building mathematical models that learn patterns from data and use those patterns to make predictions or discover structure. It sits at the intersection of statistics, computer science, and applied mathematics.

The Learning Setup

We have an outcome measurement (quantitative or categorical) that we wish to predict from a set of features (inputs). We observe a training set of (input, output) pairs and build a prediction model (learner) that generalizes to unseen data.

1.1 Real-World Learning Problems

Regression

Predict log of PSA level from clinical measurements: log cancer volume, prostate weight, age, etc. Outcome is continuous → regression.
Classification

Classification

Unsupervised

6830 genes × 64 tumor samples. Find which genes/samples cluster together. No labeled outcome → unsupervised learning.
Supervised vs. Unsupervised Learning

Supervised Learning: We observe both inputs X and outputs Y in the training data. The outcome guides the learning.

Unsupervised Learning: We observe only inputs X. The task is to find structure, clusters, or patterns in the data without outcome guidance.

Encoding Qualitative Variables

Qualitative variables must be encoded numerically. The standard approach is dummy variables: a K-level variable is represented by a vector of K binary indicators (one-hot encoding), with only one "on" at a time.

For two-class problems, a single binary code suffices: 0/1 or −1/+1.

2.3.1 Linear Models & Least Squares

The Linear Model

Given input vector \(X^T = (X_1, X_2, \ldots, X_p)\), the linear prediction model is:

\[\hat{Y} = \hat{\beta}_0 + \sum_{j=1}^{p} X_j \hat{\beta}_j \quad \text{or in matrix form:} \quad \hat{Y} = X^T \hat{\beta}\] (2.1–2.2)

The term \(\hat{\beta}_0\) is the intercept (also called the bias in ML). Including the constant 1 as the first component of X absorbs the intercept into the coefficient vector.

Fitting by Least Squares

We choose \(\hat{\beta}\) to minimize the Residual Sum of Squares (RSS):

\[\text{RSS}(\beta) = \sum_{i=1}^{N}(y_i - x_i^T \beta)^2 = (\mathbf{y} - \mathbf{X}\beta)^T(\mathbf{y} - \mathbf{X}\beta)\] (2.3–2.4)

RSS is a quadratic function of \(\beta\), so its minimum always exists. Differentiating and setting to zero gives the Normal Equations:

\[\mathbf{X}^T(\mathbf{y} - \mathbf{X}\beta) = 0\] (2.5)

If \(\mathbf{X}^T\mathbf{X}\) is nonsingular (full rank), the unique solution is:

\[\boxed{\hat{\beta} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}}\] (2.6)
Classifying with Linear Regression (0/1 Coding)

Code the two-class output: BLUE = 0, ORANGE = 1. Fit a linear regression. The predicted class is:

\[\hat{G} = \begin{cases} \text{ORANGE} & \text{if } \hat{Y} > 0.5 \\ \text{BLUE} & \text{if } \hat{Y} \leq 0.5 \end{cases}\]

The decision boundary is the set \(\{x : x^T\hat{\beta} = 0.5\}\), which is a hyperplane (a line in 2D).

Key insight: This boundary is linear and smooth but rigid — it may be suboptimal when class boundaries are nonlinear.

Geometric Interpretation: The linear model defines a hyperplane in (p+1)-dimensional input-output space. In p-dimensional input space, f(X) = X^Tβ is linear, and its gradient β points in the steepest uphill direction.

2.3.2 k-Nearest Neighbor Methods

k-NN is a fundamentally different approach: instead of imposing a global linear structure, it predicts by averaging nearby training points.

k-Nearest Neighbor Prediction
\[\hat{Y}(x) = \frac{1}{k}\sum_{x_i \in \mathcal{N}_k(x)} y_i\] (2.8)

where \(\mathcal{N}_k(x)\) is the neighborhood of \(x\) consisting of the k closest points in the training set (measured by Euclidean distance).

For classification: assign the majority class among the k nearest neighbors.

15-NN vs. 1-NN Classification

15-NN: \(\hat{Y}\) = proportion of ORANGE in the neighborhood. Classify as ORANGE if \(\hat{Y} > 0.5\) (majority vote). Smoother boundary, some bias but lower variance.

1-NN: \(\hat{Y}\) = the output \(y_\ell\) of the closest training point. Creates a Voronoi tessellation. Zero training error always, but high variance on test data!

Key insight: For k-NN, training error ≈ 0 when k=1 but test error can be large → we must use independent test data for model selection.

Characteristics
  • Makes strong structural assumptions
  • Globally linear decision boundary
  • Low Variance
  • High Bias (if wrong)
  • p parameters to estimate
  • Better for Scenario 1 (Gaussian data)
Characteristics
  • Makes minimal structural assumptions
  • Flexible, locally adaptive boundary
  • High Variance
  • Low Bias
  • N/k effective parameters
  • Better for Scenario 2 (mixture of Gaussians)
Effective Number of Parameters in k-NN

Although k-NN seems to have only one parameter (k), its effective number of parameters is N/k. As k increases, effective parameters decrease (smoother model). For k=1, effectively N parameters — the model memorizes the training data.

We cannot use training RSS to choose k, since k=1 always gives RSS=0. Use cross-validation or an independent test set instead.

2.4 Statistical Decision Theory

This section provides the theoretical foundation for why our methods work — and what they're actually trying to approximate.

Setup for Quantitative Output

Let \(X \in \mathbb{R}^p\) be the input and \(Y \in \mathbb{R}\) the output, with joint distribution \(\Pr(X,Y)\). We want \(f(X)\) to minimize the Expected Prediction Error (EPE) under squared error loss:

\[\text{EPE}(f) = \mathbb{E}(Y - f(X))^2 = \int [y - f(x)]^2 \Pr(dx, dy)\] (2.9–2.10)

Conditioning on X and minimizing pointwise:

\[f(x) = \arg\min_c \mathbb{E}_{Y|X}\left[(Y-c)^2 \mid X=x\right]\] (2.12)
The Regression Function

The optimal prediction under squared error loss is the conditional expectation:

\[\boxed{f(x) = \mathbb{E}(Y \mid X = x)}\]

This is called the regression function. The best prediction of Y at any point X=x is the conditional mean.

How Methods Approximate the Regression Function

MethodWhat it assumes about f(x)How it approximates 𝔼(Y|X=x)
k-NN Locally constant \(\hat{f}(x) = \text{Ave}(y_i \mid x_i \in \mathcal{N}_k(x))\)
Least Squares Globally linear: \(f(x) \approx x^T\beta\) \(\hat{\beta} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}\)
Additive Models \(f(X) = \sum_j f_j(X_j)\) Fit each coordinate function via k-NN or splines
k-NN as Universal Approximator

Under mild regularity conditions, as \(N, k \to \infty\) with \(k/N \to 0\):

\[\hat{f}(x) \to \mathbb{E}(Y \mid X = x)\]

However: this convergence is ruined in high dimensions — the "curse of dimensionality" makes k-NN neighborhoods far too large to be truly local.

For Qualitative Output (Classification)

Use a loss matrix \(L\) where \(L(k, \ell)\) = cost of classifying class \(G_k\) as \(G_\ell\). Minimize EPE pointwise:

\[\hat{G}(x) = \arg\min_{g \in \mathcal{G}} \sum_{k=1}^{K} L(G_k, g) \Pr(G_k \mid X = x)\] (2.21)
The Bayes Classifier (Optimal Classifier)

With the 0–1 loss function (all misclassifications equal cost), the optimal rule is:

\[\boxed{\hat{G}(x) = G_k \quad \text{if} \quad \Pr(G_k \mid X = x) = \max_{g \in \mathcal{G}} \Pr(g \mid X = x)}\]

Classify to the most probable class given X=x. The error rate of the Bayes classifier is called the Bayes rate — the irreducible lower bound on classification error.

2.5 Local Methods in High Dimensions: The Curse of Dimensionality

The Curse of Dimensionality (Bellman, 1961)

As the dimension p of the input space increases, local methods (like k-NN) fail because neighborhoods that are local in volume are not local in any single input variable.

Manifestation 1: Edge Length Explosion

For data uniformly distributed in a p-dimensional unit hypercube, to capture a fraction r of observations using a sub-cube, the expected edge length is:

\[e_p(r) = r^{1/p}\]

To capture 10% of data in 10 dimensions: \(e_{10}(0.1) = 0.1^{1/10} = 0.80\) — we need to cover 80% of each variable's range! Such a neighborhood is not local at all.

Figure: To capture even 10% of data in p=10 dimensions, you need 80% of each variable's range — so the neighborhood is not local.

Manifestation 2: All Points Near the Boundary

For N data points in a p-dimensional unit ball, the median distance from the origin to the nearest point is:

\[d(p, N) = \left(1 - \frac{1}{2}^{1/N}\right)^{1/p}\] (2.24)

For N=500, p=10: \(d \approx 0.52\) — most points are more than halfway to the boundary! Prediction near boundaries requires extrapolation, not interpolation.

Manifestation 3: Sparse Sampling

Sampling density is proportional to \(N^{1/p}\). If 100 points give dense coverage in 1D, you need \(100^{10} = 10^{20}\) points for the same density in 10D!

MSE Decomposition for 1-NN

At a test point \(x_0\), the MSE decomposes as:

\[\text{MSE}(x_0) = \underbrace{\text{Var}_\mathcal{T}(\hat{y}_0)}_{\text{Variance}} + \underbrace{[\mathbb{E}_\mathcal{T}(\hat{y}_0) - f(x_0)]^2}_{\text{Bias}^2}\] (2.25)

As p increases, the nearest neighbor strays further from \(x_0\) → both bias and variance increase. MSE → 1.0 in high dimensions for 1-NN.

How Linear Models Escape the Curse

Under the linear model \(Y = X^T\beta + \varepsilon\) with \(\varepsilon \sim N(0,\sigma^2)\):

\[\mathbb{E}_{x_0}\text{EPE}(x_0) \approx \sigma^2 \frac{p}{N} + \sigma^2\] (2.28)

EPE grows only linearly in p (not exponentially!) because the model imposes global structure. Imposing model assumptions effectively counters the curse of dimensionality.

The fundamental tradeoff: The more you restrict the class of models (impose assumptions), the less you suffer from the curse of dimensionality — but the greater your risk if those assumptions are wrong. Every method in this book navigates this tradeoff.

2.6 Statistical Models & Function Approximation

The Additive Error Model
\[Y = f(X) + \varepsilon, \quad \mathbb{E}(\varepsilon) = 0, \quad \varepsilon \perp X\] (2.29)

This is the standard statistical model for regression. The error \(\varepsilon\) captures unmeasured variables and measurement error. Under this model, \(f(x) = \mathbb{E}(Y|X=x)\).

Function Approximation via Basis Expansions

Many models can be written as linear basis expansions:

\[f_\theta(x) = \sum_{k=1}^{K} h_k(x)\,\theta_k\] (2.30)

where the basis functions \(h_k\) can be: polynomials, trigonometric functions, splines, or nonlinear transforms like the sigmoid used in neural networks:

\[h_k(x) = \sigma(x^T\beta_k) = \frac{1}{1 + e^{-x^T\beta_k}}\] (2.31)

Maximum Likelihood — Generalizing Least Squares

For a sample from density \(\Pr_\theta(y)\), the log-likelihood is:

\[L(\theta) = \sum_{i=1}^{N} \log \Pr_\theta(y_i)\] (2.33)
Equivalence: Least Squares = Maximum Likelihood (Gaussian errors)

Under \(Y = f_\theta(X) + \varepsilon\) with \(\varepsilon \sim N(0, \sigma^2)\), the conditional likelihood is \(\Pr(Y|X,\theta) = N(f_\theta(X), \sigma^2)\), and maximizing log-likelihood is equivalent to minimizing RSS:

\[L(\theta) = -\frac{N}{2}\log(2\pi) - N\log\sigma - \frac{1}{2\sigma^2}\underbrace{\sum_{i=1}^{N}(y_i - f_\theta(x_i))^2}_{\text{RSS}(\theta)}\]

The RSS is the only term involving \(\theta\), so minimizing RSS = maximizing likelihood.

2.8 Classes of Restricted Estimators

To get unique, useful solutions, we must restrict the class of allowable functions f. Three broad classes of restrictions:

Roughness Penalty (Regularization) Methods

Penalize RSS with a roughness penalty J(f):

\[\text{PRSS}(f;\lambda) = \text{RSS}(f) + \lambda J(f)\] (2.38)

Example — Cubic Smoothing Spline:

\[\text{PRSS}(f;\lambda) = \sum_{i=1}^{N}(y_i - f(x_i))^2 + \lambda \int [f''(x)]^2 dx\] (2.39)

λ=0: any interpolating function works. λ→∞: only linear functions allowed. λ controls the bias-variance tradeoff.

Bayesian interpretation: J(f) corresponds to the log-prior; PRSS is the log-posterior.

Kernel Methods & Local Regression

Specify a kernel function \(K_\lambda(x_0, x)\) that assigns weights to training points based on their distance from a target \(x_0\).

Gaussian Kernel:

\[K_\lambda(x_0, x) = \frac{1}{\lambda}\exp\left(-\frac{\|x - x_0\|^2}{2\lambda}\right)\] (2.40)

Nadaraya-Watson Estimator:

\[\hat{f}(x_0) = \frac{\sum_{i=1}^{N} K_\lambda(x_0, x_i)\, y_i}{\sum_{i=1}^{N} K_\lambda(x_0, x_i)}\] (2.41)

k-NN can be viewed as a kernel method with kernel \(K_k(x, x_0) = \mathbf{1}(\|x-x_0\| \leq \|x_{(k)} - x_0\|)\).

Basis Functions & Dictionary Methods
\[f_\theta(x) = \sum_{m=1}^{M} \theta_m h_m(x)\] (2.43)

Examples: polynomial splines, radial basis functions, neural networks. Neural network with one hidden layer:

\[f_\theta(x) = \sum_{m=1}^{M} \beta_m \sigma(\alpha_m^T x + b_m)\] (2.45)

2.9 Model Selection & The Bias–Variance Tradeoff

This is one of the most important concepts in all of statistical learning.

Bias-Variance Decomposition for k-NN

For model \(Y = f(X) + \varepsilon\), \(\mathbb{E}(\varepsilon) = 0\), \(\text{Var}(\varepsilon) = \sigma^2\):

Why Training Error is Misleading

Training error always decreases as model complexity increases. When model complexity is too high, the model memorizes the training data (overfits) and fails to generalize. Test error increases due to high variance.

We cannot use training RSS to select smoothing parameters. Methods like cross-validation or AIC/BIC (Chapter 7) are required to estimate true test error.
