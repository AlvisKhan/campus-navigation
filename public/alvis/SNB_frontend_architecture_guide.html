03 / DESIGN SYSTEM

WebGL Canvas Shaders & Glassmorphism

🌊 Three.js ColorBends Shader

Behind the application is an active 3D WebGL canvas powered by custom fragment shaders. It renders undulating organic gradient waves that react smoothly to mouse movement and theme changes:

  • Dark Mode Palette: Obsidian Jade (#0D2823, #173D35, #4E8F82, #88C7AE)
  • Light Mode Palette: Warm Cream & Mint (#F4F1E8, #E8E2D0, #B6D7D4, #7AB9B0)
  • Dynamic Properties: Warp strength, Simplex noise displacement, parallax camera angle, and automated continuous slow rotation.

The command center of the application. It dynamically calculates rolling 7-day performance metrics, presents instant query prompts, and lists active database schemas.

Key Functionalities

  • 4 Live Metric Cards: Total Queries, Active Tables, Success Rate (%), and Average Execution Latency (seconds).
  • Week-Over-Week Delta Computation: Real-time trend comparisons comparing the current 7-day window vs. previous 7-day period with color-coded directional indicators.
  • Quick Natural Language Prompt: Integrated query generation input that immediately triggers AI SQL synthesis and routes to editor.
  • Active Tables Inspector: Direct summary of discovered tables with column count badges and schema click-through.

ResultsPanel.jsx — Data Table, Skeleton Loading & CSV Exporter

Renders execution results with defensive null handling, animated skeleton loaders, formatted error banners, and browser-native CSV data export.

Core Engineering Details

  • Dynamic Column Deduction: Automatically maps keys from the first record in the JSON result payload to create table headers.
  • Client-Side CSV Generator: Encodes result rows into RFC 4180 compliant CSV strings and triggers an automatic browser Blob download link.
  • Empty & Error State Resilience: Clear visual feedback for 0 rows, execution syntax errors, or backend connectivity issues.

06 / PRESENTER PREPARATION

Audience Q&A Defense Guide

❓ "How does the frontend communicate with the AI model?"

Answer: The frontend does not call the LLM directly. Instead, it securely posts the question and the active schema definition to the backend FastAPI /generate endpoint. The backend constructs the RAG prompt, gets the generated SQL, and returns it as a JSON payload to the frontend.

❓ "How is state managed without Redux or Zustand?"

Answer: We leveraged React 19's native Context API (AuthContext) for global auth state and clean lifted component state in App.jsx with persistent synchronization to localStorage. This keeps the bundle lightweight and eliminates boilerplate.

❓ "What happens if a user submits a malicious SQL query?"

Answer: The frontend defensively wraps queries in error boundaries and displays error messages returned by the database engine. On the backend, SQLite execution handles transactions and schema isolation.

❓ "Does the WebGL background hurt browser performance?"

Answer: No. ColorBends.jsx utilizes optimized fragment shaders running directly on the GPU with low iteration count, 0.15 speed factor, and throttled mouse influence, maintaining a constant 60 FPS without CPU contention.
