1. Data & Attribute Types

Data = quantities, characters or symbols on which a computer performs operations, stored/transmitted as electrical signals and recorded on magnetic, optical or mechanical media. A dataset is a structured collection of data; a datapoint is a single instance (row) in it.

Structured vs Unstructured

  • Structured — fixed format, easily searchable (database tables, Excel sheets).
  • Semi-structured — partially organized (JSON, XML, emails).
  • Unstructured — no predefined format (images, audio, free text).

Machine Learning (Tom Mitchell): "A computer program is said to learn from experience E with respect to some task T and performance measure P, if its performance at T, measured by P, improves with experience E."

PYQ 2026 · Q1b, Q1c [b] What is Machine Learning? — see Mitchell's definition above; in short, a system that improves its performance on a task automatically through experience/data rather than being explicitly programmed with fixed rules.

[c] Equation: x2 = w1/w2·x1 + c/w2. What does "learning" mean here?
This is a straight line in the form y = mx + c used as a linear decision boundary separating two classes. "Learning" here means finding the best values of the parameters w1, w2, c from the training data so that the line correctly separates the classes (minimizes classification error) — the algorithm is not told these weights; it estimates/learns them from examples.

[d] "Supervised learning is slow and costly" — explain with justification.
Supervised learning needs a large amount of manually labelled training data before the model can learn — labelling (by domain experts) is time-consuming and expensive. Also, training itself (especially with many features/samples) requires repeated computation (e.g., calculating entropy/Gini for every attribute-split, or solving optimization problems in SVM) which grows with data size — hence "slow and costly" compared to unsupervised learning, which needs no labels.

3. Outlier Detection: Box Plot & Z-Score

Outlier — a data point that differs significantly from the rest of the observations; may indicate variability, measurement error, or a rare event.

Box Plot Method

IQR = Q3 − Q1
Lower Whisker = Q1 − 1.5 × IQR   |   Upper Whisker = Q3 + 1.5 × IQR

Any point below the Lower Whisker or above the Upper Whisker is flagged an outlier.

PYQ 2025 · Q2d Derive Upper/Lower Whisker for a standard normal, range ±2.9σ

For X ~ N(μ,σ²), standardize Z = (X−μ)/σ. Given Q1 = −0.5543σ, Q3 = +0.5543σ (≈ z-values at 25th/75th percentile):

IQR = Q3 − Q1 = 1.1086σ  ⇒  1.5×IQR = 1.663σ
Upper Whisker = Q3 + 1.5·IQR = 0.5543σ + 1.663σ = 2.217σ
Lower Whisker = Q1 − 1.5·IQR = −0.5543σ − 1.663σ = −2.217σ

To force the anomaly boundary out to ±2.9σ, the multiplying factor k must satisfy Q3+k·IQR = 2.9σ ⇒ k = (2.9−0.5543)/1.1086 ≈ 2.115 (i.e. use "2.9σ rule" instead of the standard "1.5×IQR" when extreme anomalies only are wanted).

Z-Score Method

z = x − xσ

Typically |z| > 3 (or sometimes >2) flags an outlier — it tells you how many standard deviations a point is from the mean.

(μ=5.956, σ=3.016). All |z| < 3 here, so by the standard rule none is flagged — but 13.2 is the most extreme and worth flagging if a stricter threshold (|z|>2) is used.

PYQ 2025 · Q2b (method) Boxplot on Blood Pressure / Skin Thickness — how to answer
  1. Sort the column values; find Q1 (25th percentile), Median, Q3 (75th percentile).
  2. Compute IQR = Q3−Q1, then whiskers = Q1−1.5·IQR and Q3+1.5·IQR.
  3. Any value outside the whiskers → outlier (e.g., BloodPressure = 296 and 0 in Table 1 are clear outliers — 296 mmHg is physiologically extreme, 0 is a missing-data placeholder mis-recorded as zero).
  4. Remove the flagged outliers, recompute mean and standard deviation: removing high/low extreme values pulls the mean toward the bulk of the data and reduces the standard deviation (less spread) — always state this direction of change as your justification.

4. Normalization / Scaling (Continuous Data Processing)

Normalization rescales attributes so no single feature dominates purely because of its numeric range — essential before distance-based methods (k-NN, k-Means) and neural nets.

Min-Max Normalization

v′ = v − minAmaxA − minA × (new_maxA − new_minA) + new_minA

Maps to a chosen range, e.g. [0,1]. Preserves relationships between original values, but sensitive to new outliers.

Z-score Normalization

v′ = v − AσA

Useful when min/max of the attribute are unknown or unstable (may exceed [0,1] range).

Decimal Scaling

v′ = v10j,   j = smallest integer such that max|v′| < 1

Example: values range up to 986 → divide by 1000 (j=3) → 986 becomes 0.986.

Solved Example Min–Max to [0,1]: values 5,16,32,17 with min=5, max=32.

v′(16) = (16−5)/(32−5) = 11/27 = 0.407. Similarly v′(32) = 27/27 = 1.0, v′(5) = 0.

6. Entropy & Information Gain (Decision Trees)

A Decision Tree recursively splits data using the attribute that best separates classes, starting from a Root Node down to Leaf Nodes (predictions), via internal Decision Nodes.

Impurity Measures

Entropy
Entropy(D) = −Σi=1k pi log2(pi)
Gini Index
Gini(D) = 1 − Σi=1k pi2
Classification Error
Error(D) = 1 − max(pi)

Why the negative sign? Since 0 < pi < 1, log₂(pi) is always negative (e.g. log₂0.5 = −1), so Σpilog₂(pi) ≤ 0. The leading minus sign flips this to a non-negative quantity. Entropy = 0 for a pure node (all one class); Entropy = 1 (max) when classes are perfectly mixed 50-50 — higher entropy = higher uncertainty/impurity.

Information Gain (used by ID3)

Info(D) = −Σi=1m pi log2(pi)   (entropy before split)
InfoA(D) = Σj=1v |Dj||D| × Info(Dj)   (weighted entropy after splitting on A)
Gain(A) = Info(D) − InfoA(D)

The attribute with the highest Gain is chosen at each step (root first, then recursively for children).

11. Support Vector Machines (SVM)

SVM finds the hyperplane that separates two classes with the maximum margin — the widest possible "street" between classes. Points on the margin boundary are the support vectors.

Hard-Margin Formulation

Hyperplane: w·x + b = 0  →  classify as sign(w·x + b)
Minimize  ½‖w‖2   subject to   yi(w·xi + b) ≥ 1   ∀i

Solved via Lagrange multipliers αi ≥ 0 (dual problem) — points with αi > 0 are the support vectors; all others have αi=0 and don't affect the boundary.

Soft-Margin (non-separable data)

Minimize  ½‖w‖2 + C·Σξi   subject to   yi(w·xi + b) ≥ 1 − ξi, ξi ≥ 0

ξi (slack) allows some points to violate the margin. C controls the trade-off: small C → wider margin, more tolerant of misclassification; large C → narrow margin, fewer errors but risk of overfitting.

Kernel Trick (non-linear SVM)

Map data to a higher-dimensional space Φ(x) where it becomes linearly separable. Since the dual form only needs dot products Φ(xi)·Φ(xj), a kernel function K(xi,xj) computes this without explicitly transforming the data (saves huge computation).

KernelFormula
LinearK(x,y) = x·y
PolynomialK(x,y) = (x·y + c)d
RBF (Gaussian)K(x,y) = exp(−‖x−y‖2 / 2σ2)
Worked idea (small numeric example)

Points: x₁=(2,2) class −1; x₂=(4,5) class +1; x₃=(7,4) class +1. Solve the dual to get multipliers αi, then:

w = Σ αi yi xi     b = yk − w·xk  (for any support vector k)

Once w and b are found, classify a new point x as Class +1 if w·x+b > 0, else Class −1. (Exact α values need solving the quadratic program — in exams, they are usually given or a 2–3 point toy example is used so α can be found by solving 2 simultaneous equations from the margin constraints yi(w·xi+b)=1.)

Choosing k

Rule of thumb: k ≈ √n  (n = number of training samples)
  • Use an odd k for binary classification (avoids ties).
  • Elbow Method: plot validation error vs. k; pick k where the error curve flattens ("elbow").
  • Always normalize features first — k-NN is distance-based, so unscaled features bias the result.
  • Too large k → oversmoothing, biased toward the majority class; too small k → overfits to noise.

13. Naive Bayes Classifier

A probabilistic classifier based on Bayes' Theorem with a "naive" assumption: all features are conditionally independent given the class.
P(C|X) = P(X|C) · P(C)P(X)

P(C|X)=Posterior (probability of class C given evidence X), P(X|C)=Likelihood, P(C)=Prior, P(X)=Evidence (same for all classes, so can be dropped for comparison).

Naive assumption: P(X|C) = P(x1|C) × P(x2|C) × ... × P(xn|C)
⇒ P(C|X) ∝ P(C) × Πi=1n P(xi|C)

Pick the class C that maximises this product (this is called MAP — Maximum A Posteriori).

Zero-Probability Problem & Laplace (Add-1) Smoothing

If a combination never appears in training data, its conditional probability is exactly 0, which forces the whole product to 0 regardless of other evidence — even though the combination may simply be unseen, not impossible.

P(xi|C) = count(xi, C) + 1count(C) + d  (Laplace smoothing; d = no. of distinct values of that attribute)

14. Naive Bayes for Continuous Data (Gaussian NB)

When a feature is continuous (e.g., height, temperature) rather than categorical, we can't build a frequency table. Instead, assume the feature is normally distributed within each class and use the Gaussian probability density function:

P(xi | C) = 1√(2π σC2) · exp( −(xi − xC)2 / 2σC2 )

where xC and σC are the mean and standard deviation of that feature computed only from the rows belonging to class C.

Solved Example

Class "Male" heights (cm): 170, 175, 180 → mean=175, σ≈5. Predict P(height=178 | Male):

P(178|Male) = 1√(2π·25) · exp( −(178−175)2/(2·25) ) = 0.0798 × exp(−0.18) = 0.0798×0.835 ≈ 0.0666

This density value is then multiplied with the other (categorical or continuous) feature likelihoods and the prior, exactly as in the discrete case, to get the posterior for "Male".

Alternative for continuous data: first discretize the attribute (equal-width/equal-frequency binning, Section 5) and then apply ordinary categorical Naive Bayes — mention both approaches in the exam if asked "how does Naive Bayes handle continuous attributes?"

15. Additional Solved PYQ Highlights

PYQ 2026 · Q2a Why is NearMiss-1 better than RUS (Random Under-Sampling) for imbalanced data?

RUS removes majority-class points completely at random, which can discard informative points near the decision boundary. NearMiss-1 instead selectively keeps only those majority-class points whose average distance to the k nearest minority-class points is smallest — i.e., it keeps majority points that lie close to the boundary, preserving the information needed to distinguish the classes. This gives a more informative, boundary-aware reduced dataset than RUS's blind random removal.

PYQ 2026 · Q2c Cosine Similarity — mathematical formulation
Cosine Similarity(x, y) = x · y‖x‖ ‖y‖ = Σ xiyi√(Σxi2) · √(Σyi2)

Measures the cosine of the angle between two vectors (range −1 to 1; 1 = identical direction). Distance = 1 − Cosine Similarity. Commonly used for text/high-dimensional sparse data where magnitude matters less than direction.

PYQ 2026 · Q3c, 3d, 3e

Need for PCA: Reduces a high-dimensional feature space to fewer uncorrelated "principal components" that retain most of the variance — fights the curse of dimensionality, removes redundancy/multicollinearity, speeds up training, and helps visualization, at some cost of interpretability.

Advantages of feature selection: Reduces overfitting, shortens training time, improves model interpretability, removes noisy/irrelevant features, and can improve accuracy by removing misleading attributes.

Wrapper vs Filter: Filter methods score features independently of any model (correlation, chi-square, information gain) — fast, model-agnostic. Wrapper methods evaluate feature subsets by actually training a model (e.g., forward selection, backward elimination, RFE) — slower but usually more accurate since it accounts for feature interactions.

Based on repeated patterns across both PYQs, these are likely to reappear in some form:

  1. Differentiate Gini Index and Entropy as impurity measures. — Both range differently: Entropy ∈ [0,1] (binary case, log-based), Gini ∈ [0,0.5] (binary case, quadratic). Gini is computationally cheaper (no log). Both give 0 for pure nodes and max value for a 50-50 split. ID3/C4.5 use entropy-based gain; CART uses Gini.
  2. Why does Information Gain favour high-cardinality attributes? Give an example. — see Section 8's note; e.g. splitting on a unique "Roll No" makes every leaf pure (entropy 0) giving max Gain, but this overfits and has zero generalising power. Gain Ratio (C4.5) penalises this via SplitInfo.
  3. Compute Entropy and Information Gain for a small dataset (practice with Table 1 / Table 2 style data — see Sections 7 & 9).
  4. Explain the Bias-Variance role of k in k-NN. — Small k → low bias, high variance (overfits to noise); Large k → high bias, low variance (oversmooths, underfits). Use cross-validation / elbow method to balance.
  5. Why is the SVM margin maximised rather than just finding any separating hyperplane? — A maximum-margin boundary generalises better to unseen data (lower expected test error) — it's the most "confident" separator, least sensitive to small perturbations in the data.
  6. What is the role of the parameter C in soft-margin SVM? — see Section 11: controls the trade-off between margin width and misclassification tolerance.
  7. Explain the "naive" assumption in Naive Bayes — is it realistic? Why does NB still work well? — Assumes features are conditionally independent given the class, which is rarely exactly true in real data (e.g. Color and Type of a car may be correlated). Yet NB still performs well in practice because it only needs the ranking of posterior probabilities to be correct for classification, not their exact values — errors in the independence assumption often cancel out.
  8. Difference between Filter and Wrapper feature-selection methods. — see Section 15.
  9. Explain Min-Max vs Z-score normalization — when would you prefer one over the other? — Min-Max is bounded but sensitive to new outliers (a single new max/min re-scales everything); Z-score handles unknown/unbounded ranges better and is less sensitive to a single extreme value, but the output isn't bounded to a fixed range.
  10. What is the difference between Discretization by Binning and by Clustering? — Binning uses only value order/position (equal width or equal frequency) and ignores natural groupings; Clustering (e.g. k-Means) groups by actual density/proximity of values, producing more "natural" bins but is more computationally expensive.
  11. Given a small table with a missing/None value, justify which imputation method to use and why. — Practice framing: identify if the attribute is numeric (mean/median or k-NN) or categorical (mode or class-conditional mode); justify based on % missing and whether missingness looks random.
  12. Explain Eager vs Lazy learners with two examples each. — Lazy: k-NN, case-based reasoning (no training phase, all computation deferred to prediction time). Eager: Decision Tree, SVM, Naive Bayes (build an explicit model upfront).
