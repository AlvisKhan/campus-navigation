Turing Test and its relevance (3 marks)

Proposed by Alan Turing (1950). A human judge chats by text with a hidden human and a hidden machine. If the judge cannot reliably tell which is the machine, the machine passes.

Relevance: gives an operational definition of intelligence (behaviour, not inner mind); drives NLP, knowledge representation, reasoning and learning. Criticism: Searle’s Chinese Room says passing shows imitation, not understanding.

“Computers only do what programmers tell them, so they can’t be intelligent” (2024, 2 marks)

Is the latter statement true? Only partly. A computer does execute instructions, but in machine learning the programmer specifies a learning procedure, not the behaviour. The result (e.g. a game-playing program that beats its creators) is not something the programmer wrote down.

Does it imply the former? No. Intelligence is judged by behaviour (rational, adaptive, goal-achieving), not by whether the mechanism was programmed. Humans are also “programmed” by genes and experience. This is Lady Lovelace’s objection, answered by Turing.

  • Finance: fraud detection
  • Agriculture: crop disease detection
  • Language: translation and assistants
AI handles scale, speed and complexity that manual methods cannot.

Episodic vs Sequential (2023, 3 marks)

Episodic: each percept-action pair is independent; the current choice does not affect future ones. Example: image classification on a conveyor belt, a spam filter.

Sequential: current action affects future states and rewards, so the agent must think ahead. Examples: chess, driving, maze navigation.

Agent architectures and hybrid agents (4 marks)
1Simple reflex
Condition→action rules on the current percept. Fails if the environment is partially observable.
2Model-based reflex
Keeps internal state to track unseen parts of the world.
3Goal-based
Searches or plans for actions that reach a goal.
4Utility-based
Picks the action with best expected utility, useful with trade-offs and uncertainty.
5Learning agent
Critic, learning element, performance element and problem generator improve it over time.
HybridLayered
A fast reactive layer (avoid obstacle now) sits under a slow deliberative layer (plan the route). Handles complex, dynamic worlds where pure reflex is too naive and pure planning too slow. Example: a self-driving car or warehouse robot.

Rationality link: a rational agent picks the action maximising expected performance given its percepts. The architecture is the machinery; the task environment decides which machinery is needed. Applications: medical diagnosis assistants, autonomous driving.

3 · Search foundations

Formulation · maze · UCS · termination criteria

Formulate the delivery-robot problem (2023, 4 marks)
  • State: robot’s (row, col) plus the set of packages still held or delivered, e.g. (r, c, {A,B,C held})
  • Initial state: start square, all three packages held
  • Actions: move N/S/E/W into a free square; Drop(pkg) if at that package’s location
  • Transition: move changes position; drop removes that package from the held set
  • Goal test: A, B and C all delivered to their own squares
  • Cost: 1 per action (moves and drops), minimise total
Best uninformed search for a maze with unknown structure (2025, 2 marks)

Breadth-First Search. With equal step costs it explores level by level, so the first time it reaches the exit it has used the fewest steps: complete and optimal. Cost: memory grows like bd. If memory is tight, use Iterative Deepening (BFS optimality, DFS memory).

UCS and the priority queue (2024, 6 marks)

UCS expands the frontier node with the lowest path cost g(n) so far. The frontier is a priority queue keyed on g(n): pop gives the cheapest node in O(log n), and if a cheaper route to a queued node appears, its key is updated.

Example: S→A(1), S→B(5), A→G(10), B→G(2). Queue: A(1), B(5). Expand A, push G(11). Queue: B(5), G(11). Expand B, push G(7) which replaces G(11). Pop G(7): path S-B-G costs 7, the optimal. The queue guarantees the next expanded node is always the cheapest, so the first goal popped is optimal (with non-negative costs).

A* explained with pseudocode and key components (2023, 5 marks)

A* finds the cheapest path by always expanding the open node with the lowest f(n) = g(n) + h(n). g is the cost paid so far, h is the estimated cost still to go (straight-line distance to Bucharest).

A_STAR(start, goal):
  OPEN  = priority queue ordered by f; insert start (g=0, f=h(start))
  CLOSED = empty set
  while OPEN not empty:
    n = OPEN.pop_lowest_f()
    if n == goal: return path(n)          # optimal if h admissible
    add n to CLOSED
    for each neighbour m of n:
      g_new = g(n) + cost(n, m)
      if m in CLOSED and g_new >= g(m): continue
      if m not in OPEN or g_new < g(m):
        g(m) = g_new; f(m) = g_new + h(m); parent(m) = n
        insert or update m in OPEN
  return FAILURE
OPEN / CLOSED lists
Frontier to expand, and nodes already expanded.
g(n)
Exact cost from start to n.
h(n)
Heuristic estimate to goal. Admissible = never overestimates. Consistent = h(n) ≤ cost(n,m) + h(m).
Parent pointers
Rebuild the path once the goal is popped.

Properties: complete and optimal when h is admissible (consistent for graph search). With h=0 it becomes UCS; with g=0 it becomes greedy best-first.

5 · Local search & AO*

Hill climbing · local maxima · AO*

Hill climbing is local search + local maxima problem (2023 4 marks, 2024 2 marks)

Hill climbing keeps only the current state and moves to the best neighbour by the objective function, stopping when none is better. It uses no frontier and no path memory: constant memory, which is why it is a local search algorithm. Example: 8-queens, moving one queen to reduce conflicts.

Local maxima problem: the algorithm stops on a peak higher than its neighbours but lower than the global best. Related traps: plateau (flat, no direction) and ridge (needs a diagonal move). Fixes: random restarts, simulated annealing, sideways moves, stochastic hill climbing.

“AO* does not explore all solution paths once it finds a solution” (2023, 2024)

AO* works on an AND-OR graph. AND arcs need all children solved; OR arcs need one. It repeatedly: (1) follows the currently best marked path to an unexpanded node, (2) expands it, (3) back-propagates updated costs upward, choosing the cheapest option at each OR node, (4) marks nodes SOLVED when their required children are solved. It stops when the root is SOLVED.

Example: A has OR-branch B (cost 5) and AND-branch C+D (cost 3+4=7 as estimated). AO* explores the cheapest, B; it expands B and finds it solved for a real cost of 6. C+D is still estimated at 7 ≥ 6, so it is never expanded. Root A is SOLVED via B: the costlier alternative was never explored, saving time. (This holds when heuristics are admissible.)

Key phrase for full marks: “only the current best partial solution graph is expanded; other branches are pruned by their higher estimates.”
Second AO* example with numbers: cost revision and switching branches

Each arc costs 1. Estimated h values: B=5, C=3, D=4, E=2, F=2. Root A has an OR choice: go through B, or through the AND pair (C and D).

  • Step 1. Via B: 1 + 5 = 6. Via C+D: (1+3) + (1+4) = 9. Choose B (6 < 9).
  • Step 2. Expand B. Suppose B is an AND of E and F: (1+2) + (1+2) = 6, so B = 6 and A via B = 7. Still below 9, keep B.
  • Step 3. Expanding E reveals its real cost is 5, not 2. Back-propagate: B = (1+5) + (1+2) = 9, so A via B = 10.
  • Step 4. Now 10 > 9, so the best partial solution switches to C+D. Expand C and D, mark them and A SOLVED, cost 9.

Points to state in the exam: only the current best branch is expanded, costs are revised bottom-up, and the best branch can change. The AND pair is never partly counted, and the graph stays unexplored where estimates are worse.

6 · Propositional logic

Tautology proofs · satisfiability · modus ponens vs tollens

2025 · Is ((p→r) ∧ (q→r)) → ((p∨q) → r) a tautology? (2 marks)

Answer: Yes, it is a tautology.

Method: proof by contradiction (no truth table). We assume the formula can be false and show that this is impossible.

Step 1. An implication A → B is false only when A is true and B is false. So if the whole formula is false:

(p→r) ∧ (q→r) = T   and   (p∨q) → r = F

Step 2. Apply the same rule to (p∨q) → r being false:

p∨q = T   and   r = F

Step 3. A conjunction is true only when both parts are true, so:

p→r = T   and   q→r = T

Step 4. Use r = F from Step 2.

p→r = T with r = F  ⇒  p must be F  (T→F would be false)
q→r = T with r = F  ⇒  q must be F

Step 5. Then p∨q = F∨F = F. But Step 2 said p∨q = T.

p∨q = T and p∨q = F  ⇒  contradiction

Conclusion: our assumption was wrong. The formula can never be false, so it is a tautology. (This is the rule of proof by cases: if p gives r and q gives r, then p-or-q gives r.)

2024 · Prove ((p→q) ∧ (r→q)) → (r→p) is a tautology (4 marks)
Read carefully: this formula is not a tautology, so it cannot be proved. In the exam, say so and prove why using a counterexample. That earns the marks. Two methods are shown below; Method 1 is enough.

Method 1 · Find a counterexample

A formula is a tautology only if it is true for every assignment. One assignment that makes it false is enough to disprove it.

Step 1. To make the whole formula false, we need the antecedent true and the consequent false:

(p→q) ∧ (r→q) = T   and   r→p = F

Step 2. r→p is false only when r is true and p is false:

r = T,  p = F

Step 3. Now check the antecedent with p = F, r = T.

p→q = F→q = T  for any q (a false premise makes the implication true)
r→q = T→q = q  so for this to be true we need q = T

Step 4. So the counterexample is p = F, q = T, r = T. Substitute it in:

PartWorkingValue
p → qF → TT
r → qT → TT
(p→q) ∧ (r→q)T ∧ TT
r → pT → FF
Whole formulaT → FF

Conclusion: the formula is false for p=F, q=T, r=T, so it is not a tautology. It is only satisfiable: for example p=T, q=T, r=T makes it true.

Method 2 · Simplify with equivalences (no truth table)

1.  (p→q) ∧ (r→q)  ≡  (¬p∨q) ∧ (¬r∨q)   (implication elimination)

2.  ≡  (¬p∧¬r) ∨ q   (distributive law)

3.  Whole formula:  ¬[(¬p∧¬r) ∨ q] ∨ (¬r∨p)   (A→B ≡ ¬A∨B)

4.  ≡  [(p∨r) ∧ ¬q] ∨ ¬r ∨ p   (De Morgan)

5.  Check when this is false. We need p = F and ¬r = F, so r = T. Then the bracket reduces to (T) ∧ ¬q = ¬q, which is false when q = T.

6.  The formula is therefore false exactly for p=F, q=T, r=T, so it is not a tautology.

Likely intended question

The printed question probably meant the hypothetical syllogism ((p→q) ∧ (q→r)) → (p→r), which is a tautology. If your teacher confirms this version, write this:

Step 1. Assume it is false. Then (p→q) ∧ (q→r) = T and p→r = F.

Step 2. p→r = F gives  p = T, r = F.

Step 3. p→q = T with p = T gives  q = T.

Step 4. q→r = T with q = T gives  r = T. But Step 2 said r = F.

r = T and r = F  ⇒  contradiction

Conclusion: the formula can never be false, so it is a tautology.

Satisfiability (2 marks)

A formula is satisfiable if at least one truth assignment makes it true. If every assignment makes it true it is valid (tautology); if none does, it is unsatisfiable (contradiction). Example: p∧q is satisfiable (p=q=T); p∧¬p is not. SAT was the first NP-complete problem.

Major challenges in NLP (2 marks)
  • Ambiguity: lexical (“bank”), syntactic (“I saw the man with a telescope”), semantic and referential (“he” = who?)

Q1. Run A* from Timisoara to Bucharest if h(Mehadia) were 300 instead of 241. What changes?
Mehadia's f becomes 181 + 300 = 481. It is still below Arad's 484, so it is expanded at the same point and the trace is unchanged: the answer stays 536. The new value is also still admissible, because the true remaining cost from Mehadia (75+120+138+101 = 434) is at least 300.
Q2. Greedy best-first from Timisoara: which path, and is it optimal?
Greedy uses only h. From Timisoara: Arad 366 vs Lugoj 244 → Lugoj; then Mehadia 241 → Dobreta 242 → Craiova 160 → Pitesti 98 → Bucharest. Cost 111+70+75+120+138+101 = 615. Not optimal (A* gives 536).
Q3. Show that BFS is not optimal on weighted graphs.
BFS minimises number of edges. S→G directly with cost 10 has 1 edge; S→A→G with costs 1+1 has 2 edges. BFS returns the cost-10 path; UCS returns the cost-2 path.
Q4. Is p → (q → p) a tautology?
Yes. Suppose it is false: p=T and q→p false, which needs p=F. Contradiction, so it is always true.
Q5. Classify: (a) crossword solving, (b) poker, (c) taxi driving.
(a) fully observable, deterministic, sequential, static, single agent. (b) partially observable, stochastic, sequential, multi-agent. (c) partially observable, stochastic, sequential, dynamic, continuous, multi-agent.
