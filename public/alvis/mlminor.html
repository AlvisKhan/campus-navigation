Learning, data & the pipeline

PDF pages 12–38 · numbered slides 5–30
Machine learning in an exam answer

A program learns when experience E improves its performance P on a task T.

For spam filtering: T = classify email, E = labelled example emails, P = performance on unseen email.

Conventional programming: data + rules → output.

Supervised learning: data + known outputs → learned model.

model + new data → prediction.

Which learning problem is it?

Supervised regressionKnown numeric targetsPrice, temperature
UnsupervisedNo class labelsClusters or associations
ReinforcementRewards from interactionsA policy for choosing actions
Semi-supervisedSome labelled + much unlabelled dataUse both to learn a predictor

Why ML? Useful when explicit rules are difficult to write, experts cannot fully articulate their reasoning, the environment changes, or behaviour needs personalization.

Use a standard algorithm for tasks such as sorting where exact rules already exist.

Vocabulary that earns easy marks

Dataset: collection of observations. Datapoint/instance: one row. Attribute/feature: input property. Label/target: output to predict.

Structured data has a fixed schema (tables).

Pipeline

Define task → collect and understand data → split train/validation/test → fit cleaning, encoding and scaling on training data → train model → tune using validation → evaluate once on held-out test → predict and monitor.

Leakage trap: computing imputation means or scaling ranges using the test set leaks information.

Apply training-derived transformations to validation/test.

Write a 4-mark answer: supervised vs unsupervised learning.

Supervised learning uses input–target pairs to learn a mapping and predict labels or values for unseen instances.

Classification predicts categories.

regression predicts numbers.

Unsupervised learning uses inputs without known target labels to discover structure, such as clusters.

Example: labelled spam detection versus grouping customers by similarity.

Recall: Is a postcode quantitative? Is a star rating interval-scaled?

A postcode is nominal even if written as digits.

A star rating is usually ordinal: order is meaningful, but equal psychological gaps between ratings are not guaranteed.

03

Classification & decision trees

PDF pages 105–176 · slides 86–152

Classification is a two-step process

Construction: fit a model from labelled training tuples. Usage/evaluation: compare predicted labels with known labels in an independent test set.

Accuracy = number correct / number tested.

Strong training accuracy alone does not establish generalization.

A tree’s root contains the full dataset.

internal nodes test features.

branches represent outcomes.

leaves predict classes or numbers.

Training chooses useful splits recursively.

Prediction follows one root-to-leaf path.

Three impurity measures
H(D) = −Σ pᵢ log₂pᵢ
Gini(D) = 1 − Σ pᵢ²
Error(D) = 1 − maxᵢ pᵢ

Take 0 log₂0=0.

Pure node: all three are 0.

Balanced binary node: entropy=1, Gini=0.5, error=0.5.

For K equally likely classes: H=log₂K, Gini=1−1/K.

The minus sign makes entropy nonnegative because log probabilities are ≤0.

Higher entropy means greater class uncertainty.

A pure node is a desirable terminal node, even though it contains no uncertainty for choosing a further split.

ID3: choose maximum information gain

Hafter(A) = Σⱼ (|Dⱼ|/|D|) H(Dⱼ)
IG(A) = H(D) − Hafter(A)

Algorithm: if node pure, return its class.

otherwise compute candidate gains, choose the maximum, partition by attribute values, recurse on each subset.

If no features remain or a stop condition holds, return the majority class.

Empty branches use a stated fallback, usually parent majority.

C4.5: fix the many-values bias

SplitInfo(A) = −Σⱼ qⱼ log₂qⱼ   where qⱼ = |Dⱼ|/|D|
GainRatio(A) = IG(A)/SplitInfo(A)

SplitInfo uses branch sizes, not class proportions within each branch. High-cardinality attributes can make singleton pure leaves and artificially look excellent under IG. Gain ratio penalizes that partition complexity. Skip a split with SplitInfo=0. Stopping, pruning and generalization

Pre-pruning: stop early using max depth, minimum split/leaf size, minimum gain, or max leaf count. Post-pruning: grow then remove subtrees.

CART cost-complexity objective:

Rα(T) = R(T)+α×number of leaves

Larger α strengthens the penalty for complexity.

Choose settings using validation.

Underfitting = model too simple.

overfitting = captures training noise and fails to generalize.

Strengths: understandable rules, nonlinear relationships, interactions, little scaling needed. Limitations: high variance, greedy local choices, unstable trees, overfitting, axis-aligned boundaries.

6-mark model answer: explain how ID3 constructs a tree.

Start with all labelled training examples.

Compute parent entropy from class proportions.

For each candidate feature, partition the examples by its values and compute the weighted entropy of the children.

Information gain is parent entropy minus that weighted entropy.

Choose the feature with maximum gain.

create branches and repeat within each subset.

Stop at a pure node or when no useful feature remains, assigning a class or majority fallback.

Raw IG favours many-valued attributes and can overfit.

gain ratio or pruning can reduce this problem.

SVM: geometry, derivation & numericals

PDF pages 177–207 · slides 153–177
The idea

An SVM chooses a separating hyperplane with maximum margin between two classes.

Let yᵢ∈{−1,+1}.

the decision function is f(x)=wᵀx+b and prediction is sign(f(x)).

The vector w is normal to the hyperplane.

Boundary: wᵀx+b = 0
Margin planes: wᵀx+b = ±1
Distance to boundary = |wᵀx+b|/‖w‖
Full margin = 2/‖w‖

One-sided margin is 1/‖w‖.

The ±1 convention fixes scaling.

multiplying w and b by a constant preserves the boundary but changes their functional scores.

Hard-margin primal → dual: learn this sequence

Step 1Constraints: correctly classify every training point with canonical functional margin: yᵢ(wᵀxᵢ+b)≥1.

Step 2Primal: minimize ½‖w‖² subject to those constraints.

Smaller ‖w‖ means larger geometric margin.

Step 3Lagrangian: L=½wᵀw+Σᵢαᵢ[1−yᵢ(wᵀxᵢ+b)], with αᵢ≥0.

Step 4Stationarity: ∂L/∂w=0 → w=Σᵢαᵢyᵢxᵢ.

∂L/∂b=0 → Σᵢαᵢyᵢ=0.

Step 5Substitute: maximize W(α)=Σᵢαᵢ−½ΣᵢΣⱼαᵢαⱼyᵢyⱼ(xᵢᵀxⱼ), subject to αᵢ≥0 and Σᵢαᵢyᵢ=0.

Step 6Recover: w=Σαᵢyᵢxᵢ.

For a margin support vector, b=yᵢ−wᵀxᵢ.

Step 7KKT check: αᵢ[yᵢf(xᵢ)−1]=0.

Positive α implies an active margin constraint.

A margin point can have α=0 in a degenerate solution.

k-NN is instance-based and nonparametric: it does not assume a fixed probability distribution or learn a fixed-form global boundary. k is still a hyperparameter.

  1. Scale features using training statistics.

Choosing k and explaining trade-offs

k=1 is highly local and sensitive to noise (low bias, high variance).

Very large k smooths the boundary but may underfit and favour the majority class (higher bias, lower variance).

An odd k avoids a two-class vote tie, but not tied distances or all multiclass ties. √n is only a starting heuristic.

Validate several k values and select by held-out error.

an elbow is a visual aid, not a guaranteed optimum.

Limitations: costly queries, storage, sensitivity to irrelevant features and scale, and unreliable distance contrast in high dimensions.

Plain brute-force distance computation costs roughly O(nd) per query before neighbour selection.

Naive Bayes & zero probabilities

PDF pages 248–260 · slides 201–213
Bayes theorem
P(C|X) = P(X|C) P(C) / P(X)

Prior P(C): belief before observing X. Likelihood P(X|C): feature probability under the class. Posterior P(C|X): updated class probability. Evidence P(X): normalization.

Naive Bayes assumes features are conditionally independent given the class, not unconditionally independent.

Then:

P(X|C) = ∏ⱼ P(xⱼ|C)
score(C) = P(C)∏ⱼP(xⱼ|C)
Ĉ = argmax score(C)

Estimate priors and feature likelihoods during training, so this is eager learning.

Evidence is the same for all candidate classes for one query, so it can be omitted for comparison.

Scores are not normalized posteriors.

divide by the sum of class scores when probabilities are requested.

Short-answer bank

1. Distinguish noise and outliers.

Noise is random measurement error.

Outliers differ greatly from most observations and may be noise or legitimate rare cases.

2. Why not normalize using the full dataset before splitting?

It leaks information from held-out observations into training.

Fit transforms on training only.

3. Entropy versus split information?

Entropy uses class probabilities in a node.

SplitInfo uses sizes of the branches created by a feature.

4. How can information gain choose a useless ID?

Each ID produces a singleton pure child, reducing weighted class entropy to zero while memorizing training data.

5. Does gain-ratio numerator measure branch balance?

No.

IG measures reduction in class uncertainty.

SplitInfo describes branch-size distribution.

6. Why does CART not need feature normalization?

A strictly monotone rescaling preserves feature order and corresponding threshold partitions.

distances are not used.

7. What does a support vector do?

It has nonzero coefficient in the dual representation and influences the boundary.

in hard margin it lies on a margin plane.

8. Why does the SVM dual enable kernels?

Input dependence occurs only through dot products, which can be replaced with mapped-space inner products.

9. How do you compute b for soft margin?

Use a free support vector with 0<α<C: b=y−ΣαᵢyᵢK(xᵢ,x).

If none exist, more careful KKT-bound handling is needed.

10. What does “nonparametric k-NN” mean?

No fixed-form distribution or finite-dimensional global boundary is assumed.

It still has hyperparameters such as k.

11. Why drop P(X) during Bayes classification?

For a fixed query it is common to all classes and cannot change the maximizing class.

12. What is the difference between pruning and reduction?

Pruning simplifies a learned tree.

data reduction simplifies the input representation or volume.

Q1 · 6 marks. (a) Explain interval vs ratio scale (2). (b) Q₁=8, Q₃=16: find fences and test 29 (2). (c) Normalize 15 from [5,25] to [0,1] and decimal-scale max=125 (2).
Answer 1CS431 · Minor mock

(a) Interval and ratio scales

An interval scale has equal units, so differences between values are meaningful. Its zero is arbitrary.

For example, Celsius temperature is interval-scaled. A temperature of 20°C is not twice as hot as 10°C.

A ratio scale has equal units and a meaningful absolute zero. Therefore, both differences and ratios are meaningful.

For example, mass is ratio-scaled. A mass of 20 kg is twice 10 kg.

(b) Finding the outlier

Given, Q₁ = 8 and Q₃ = 16.

IQR = Q₃ − Q₁
= 16 − 8 = 8

The lower and upper fences are

L = Q₁ − 1.5(IQR)
= 8 − 1.5(8) = −4
U = Q₃ + 1.5(IQR)
= 16 + 1.5(8) = 28

The given observation is 29.

29 > 28

∴ 29 lies above the upper fence and is an outlier.

(c) Normalization and decimal scaling

For min–max normalization to [0, 1],

x′ = x − minmax − min
= 15 − 525 − 5
= 1020 = 0.5

∴ The normalized value is 0.5.

For decimal scaling, the maximum absolute value is 125. Choose the smallest j such that

12510ʲ < 1

With j = 3,

x′ = 1251000 = 0.125

∴ Use j = 3. The scaled maximum is 0.125.

Answer 2CS431 · Minor mock

(a) Entropy, information gain and gain ratio

The parent contains 4 Yes and 4 No examples.

p(Yes) = p(No) = 4/8 = 1/2
H(D) = −(1/2) log₂(1/2) − (1/2) log₂(1/2)
= 1 bit

The two branches contain (3 Yes, 1 No) and (1 Yes, 3 No). Their class proportions are reversed, so their entropies are equal.

(b) ID bias and pruning

A unique ID splits the training data into one-example branches. Every such branch is pure, so its entropy is zero.

This gives a high information gain even when the ID has no useful relationship with the target. The tree memorizes training examples and may fail on unseen data.

One way to control this is cost-complexity post-pruning. First grow the tree, then remove subtrees by balancing prediction error against tree size:

Rα(T) = R(T) + α × number of leaves

Here, R(T) is the tree’s empirical risk and α controls the complexity penalty. A larger α favours a smaller tree. Choose α using validation data.

Q3 · 9 marks. Write hard-margin primal and derive its dual (5). For w=(3,4),b=−5 find full margin and label of (1,1) (2). Explain C and the soft-margin multiplier bound (2).
Answer 3CS431 · Minor mock

(a) Hard-margin primal and dual

Let the training examples be (xᵢ, yᵢ), where yᵢ ∈ {−1, +1}.

The separating function is

f(x) = wᵀx + b

To maximize the margin, minimize the squared norm of w.

Primal problem

minw,b   ½‖w‖²

subject to

yᵢ(wᵀxᵢ + b) ≥ 1,   for every i.

Introduce multipliers αᵢ ≥ 0. The Lagrangian is

L = ½wᵀw + Σᵢ αᵢ[1 − yᵢ(wᵀxᵢ + b)]

At stationarity,

∂L/∂w = w − Σᵢ αᵢyᵢxᵢ = 0
⇒ w = Σᵢ αᵢyᵢxᵢ
∂L/∂b = −Σᵢ αᵢyᵢ = 0
⇒ Σᵢ αᵢyᵢ = 0

Substituting into L gives

W(α) = Σᵢ αᵢ − ½ΣᵢΣⱼ αᵢαⱼyᵢyⱼ(xᵢᵀxⱼ)

Dual problem

maxα   W(α)

subject to

αᵢ ≥ 0,   Σᵢ αᵢyᵢ = 0.

This is the hard-margin SVM dual. Its input dependence is only through dot products.

(b) Margin and prediction

Given, w = (3, 4) and b = −5.

‖w‖ = √(3² + 4²) = √25 = 5
Full margin = 2‖w‖ = 25 = 0.4

For x = (1, 1),

f(x) = 3(1) + 4(1) − 5
= 2 > 0

∴ The full margin is 0.4 and the predicted class is +1.

(c) Role of C and the multiplier bound

In soft-margin SVM, the objective is

min   ½‖w‖² + CΣᵢ ξᵢ

C controls the penalty for margin violations. A larger C puts more emphasis on reducing violations. A smaller C tolerates more violations relative to the margin objective.

Let μᵢ ≥ 0 be the multiplier for ξᵢ ≥ 0. Stationarity with respect to ξᵢ gives

∂L/∂ξᵢ = C − αᵢ − μᵢ = 0
αᵢ = C − μᵢ

Since μᵢ ≥ 0, αᵢ ≤ C. Also, αᵢ ≥ 0.

∴ 0 ≤ αᵢ ≤ C.

The three nearest labels are Y, N and Y.

There are two Y votes and one N vote.

∴ The k-NN prediction is Y.

Feature scaling is needed because a feature with a large numerical range can dominate distance calculations. Scaling makes the feature contributions more comparable.

The score of a class is its prior multiplied by the conditional likelihoods.

score(Y) = 0.6 × 0.5 × 0.2
= 0.06

= 0.08

Since 0.08 > 0.06,

∴ Predict class N.

P(Y|X) = 0.060.14 = 37 ≈ 0.4286

Here, nC is the number of training examples in class C. Adding one prevents an unseen category from receiving zero probability.

Broad syllabus versus this deck

PDF p17 names probability primer, Bayes decision theory, maximum-likelihood and Bayesian parameter estimation, nonparametric techniques, Bayes networks, optimization, linear discriminants, unsupervised/semi-supervised/reinforcement learning, statistical learning, PAC and Occam’s razor.

The deck develops only some of these through trees, SVM, k-NN and Naive Bayes.

The following is a brief safety net, not a substitute for missing lecture material.

Probability primer

P(A|B)=P(A∩B)/P(B) when P(B)>0.

P(A∪B)=P(A)+P(B)−P(A∩B).

Total probability: P(X)=ΣC P(X|C)P(C).

Conditional independence: P(A,B|C)=P(A|C)P(B|C).

Bayes decision theory

Under equal 0–1 misclassification cost, choose the largest posterior.

With unequal costs, choose the action minimizing conditional expected loss ΣC loss(action,C)P(C|X).

MLE versus Bayesian estimation

MLE maximizes likelihood P(D|θ).

Bayesian estimation combines likelihood with prior P(θ) to obtain P(θ|D) proportional to P(D|θ)P(θ).

MAP maximizes that posterior.

These are not fully derived in the deck.

Bayesian networks and linear discriminants

A Bayesian network is a directed acyclic graph encoding factorized joint probabilities through parent-conditioned terms.

A linear discriminant has form gC(x)=wCᵀx+bC.

choose the largest class score.

PAC / Occam / learning settings

PAC asks for a probably approximately correct hypothesis: error at most ε with probability at least 1−δ under stated assumptions.

Occam’s razor favours simpler hypotheses when fit is comparable.

Unsupervised discovers unlabelled structure.

semi-supervised uses both labelled and unlabelled examples.

reinforcement learns a policy from rewards.
