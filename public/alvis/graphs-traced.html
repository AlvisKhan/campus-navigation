    What is a graph? Fundamental anatomy

    A graph is a discrete mathematical structure consisting of a set of vertices (objects) and a set of edges (relations). Getting crisp on graph vocabulary unlocks instant problem modeling.

    Vertices & Edges

    A vertex (node) is an entity: a person, city, router, or game state. An edge connects two vertices. Formally, G = (V, E) where V is the set of vertices and E ⊆ V × V.

    Directed vs. Undirected

    In an undirected graph, edges are bidirectional (friendships, two-way roads). In a directed graph (digraph), edges have arrows pointing from source to destination (Twitter follows, prerequisites, web links).

    Weighted vs. Unweighted

    In weighted graphs, each edge has a numeric weight (distance, latency, cost). In unweighted graphs, every edge has uniform cost 1, which means plain BFS finds optimal paths in O(V + E) time.

    Degree & Handshaking Theorem

    The degree of vertex u is the number of incident edges. In directed graphs, split into in-degree (incoming) and out-degree (outgoing).
    Handshaking Lemma: ∑ deg(v) = 2|E| (the sum of degrees is always even).

    Essential Graph Topologies

    Tree

    Connected, acyclic graph. With N vertices, it has exactly N − 1 edges. Exactly one unique path between any two vertices.

    DAG

    Directed Acyclic Graph. The bedrock of build systems, course requirements, and dynamic programming on graphs. Topological sorting is only defined on DAGs.

    Bipartite

    Vertices can be partitioned into two sets U and V such that no edge connects two vertices in the same set. Contains no odd cycles!

    Complete (Kₙ)

    Every pair of distinct vertices is connected by a unique edge. Contains N(N − 1)/2 edges. Highly dense graph.

    💡 Check yourself — A graph has 7 vertices and each vertex has degree 3. Can such a graph exist?
    No! By the Handshaking Lemma, the sum of degrees across all vertices must equal 2 × |E|, which is always an even integer. Here, the sum of degrees would be 7 × 3 = 21, which is odd. Thus, no such graph can exist.

    Representing graphs in modern C++

    Choosing the right data structure directly determines your time and space complexity. Three core representations dominate C++ graph problems.

    1. Adjacency list 95% of problems

    Stores each node's neighbors in an array of vectors. Space: O(V + E). Optimal for sparse graphs where E ≪ V².

    adj_list.cpp
    #include <vector>
#include <iostream>

using namespace std;

int n, m; // n = nodes, m = edges
vector<vector<int>> adj;

void buildUnweighted() {
    adj.assign(n, vector<int>());
    for (int i = 0; i < m; ++i) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u); // omit if directed
    }
}

// Weighted Graph: vector<pair<neighbor, weight>>
vector<vector<pair<int, int>>> wadj;
void addWeightedEdge(int u, int v, int w) {
    wadj[u].push_back({v, w});
    wadj[v].push_back({u, w});
}

    2. Adjacency matrix Dense / Small V

    A V × V 2D matrix where mat[u][v] stores edge existence or weight. Edge existence check in O(1) time. Space: O(V²).

    adj_matrix.cpp
    #include <vector>
using namespace std;

const int INF = 1e9;
vector<vector<int>> mat(n, vector<int>(n, INF));

void initMatrix() {
    for (int i = 0; i < n; i++) mat[i][i] = 0;
    for (int i = 0; i < m; i++) {
        int u, v, w; cin >> u >> v >> w;
        mat[u][v] = w;
        mat[v][u] = w; // undirected
    }
}

    3. Implicit Grid Graphs (The 2D Matrix Pattern)

    In countless interview questions (e.g. Number of Islands, Rotting Oranges, Shortest Path in Binary Matrix), you are given a 2D grid where each cell is a vertex and orthogonal neighbors are edges. Never convert the grid into an adjacency list! Traverse it implicitly using direction arrays:

    grid_graph_template.cpp
    // 4-directional delta arrays (North, South, West, East)
const int dr[] = {-1, 1, 0, 0};
const int dc[] = {0, 0, -1, 1};

bool isValid(int r, int c, int R, int C, vector<vector<char>>& grid) {
    return (r >= 0 && r < R && c >= 0 && c < C && grid[r][c] == '1');
}

    Breadth-First Search (BFS)

    BFS expands in concentric ripples layer-by-layer. Because it visits all nodes at distance d before visiting any node at distance d + 1, BFS finds shortest paths in unweighted graphs in O(V + E) time.

    Critical BFS Variants in Interviews

    Multi-Source BFS

    When you need the distance from any fire / water / guard to all other cells, push all starting sources into the queue at t = 0 before the loop starts. The wave naturally propagates simultaneously!

    0-1 BFS (std::deque)

    When edge weights are only 0 or 1, use std::deque. Push 0-weight edges to push_front() and 1-weight edges to push_back(). Gives Dijkstra shortest path in O(V + E)!

    Common Bug: Always mark a node visited = true at enqueue time (when pushing), NOT at dequeue time (when popping). If you wait until dequeue, the same node will be enqueued dozens of times across multiple neighbors, causing O(2ⁿ) exponential memory blowup!

    Depth-First Search (DFS) & Call Stack

    DFS plunges along a single path as deeply as possible before backtracking. Its recursive formulation matches the system call stack, making it the ideal tool for path finding, connectivity, topological ordering, and tree recursion.

    DFS Edge Classification in Directed Graphs

    When running DFS on a directed graph, every edge u → v falls into one of four categories:

    1. Tree Edge

    Edge leading to an unvisited node during exploration. Forms the DFS tree.

    2. Back Edge

    Edge pointing from a node to one of its ancestors on the current recursion stack. Proves a cycle exists!

    3. Forward Edge

    Edge pointing from an ancestor to an already finished descendant in the DFS tree.

    4. Cross Edge

    Edge connecting two nodes that are not ancestor/descendant of each other.

    Cycle detection & 3-Coloring DFS

    Cycle detection is among the most frequent interview problems (e.g., Course Schedule). The algorithm changes fundamentally between undirected and directed graphs.

    Undirected Cycle Check (Parent Pointer)

    If DFS reaches an already-visited neighbor that is not the immediate parent, that edge is a back-edge and completes a cycle.

    cycle_undirected.cpp
    bool hasCycleUndirected(int u, int p, vector<vector<int>>& adj, vector<bool>& vis) {
    vis[u] = true;
    for (int v : adj[u]) {
        if (!vis[v]) {
            if (hasCycleUndirected(v, u, adj, vis)) return true;
        } else if (v != p) {
            return true; // back-edge found
        }
    }
    return false;
}

    Directed Cycle Check (3-Color State)

    Parent pointers fail in digraphs. Track vertex state: 0 = White (unvisited), 1 = Gray (in active recursion stack), 2 = Black (finished).

    cycle_directed_3color.cpp
    // 0: Unvisited, 1: Visiting (In Stack), 2: Visited (Done)
bool dfsCycle3Color(int u, vector<vector<int>>& adj, vector<int>& state) {
    state[u] = 1; // Gray: currently exploring path
    for (int v : adj[u]) {
        if (state[v] == 1) return true; // hit active stack node => cycle!
        if (state[v] == 0 && dfsCycle3Color(v, adj, state)) return true;
    }
    state[u] = 2; // Black: completely safe
    return false;
}

    Shortest paths: Dijkstra & Bellman-Ford

    Finding the shortest path depends on edge weights: Unweighted → BFS; Non-negative weights → Dijkstra; Negative weights → Bellman-Ford; All pairs → Floyd-Warshall.

    1. Dijkstra's Algorithm Non-Negative Weights

    Greedily finalizes the shortest distance node from a min-priority-queue. Runs in O((V + E) log V) time.

    2. Bellman-Ford Negative Weights & Cycles

    Relaxes all E edges V − 1 times. If a V-th pass still reduces any distance, a negative weight cycle exists! Space: O(V), Time: O(V · E).

    bellman_ford.cpp
    vector<int> bellmanFord(int src, int n, vector<array<int,3>>& edges) {
    vector<int> dist(n, INF);
    dist[src] = 0;
    for (int i = 0; i < n - 1; ++i) {
        for (auto& [u, v, w] : edges) {
            if (dist[u] != INF && dist[u] + w < dist[v])
                dist[v] = dist[u] + w;
        }
    }
    // Check for negative cycle
    for (auto& [u, v, w] : edges) {
        if (dist[u] != INF && dist[u] + w < dist[v])
            throw runtime_error("Negative cycle detected");
    }
    return dist;
}

    3. Floyd-Warshall All-Pairs Shortest Path

    Computes shortest paths between every pair in O(V³). Dynamic programming formulation: d[i][j] = min(d[i][j], d[i][k] + d[k][j]).

    floyd_warshall.cpp
    // k MUST be the outermost loop!
for (int k = 0; k < n; ++k)
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            if (dist[i][k] < INF && dist[k][j] < INF)
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);

    Minimum Spanning Trees (MST) & DSU

    An MST is a subset of edges connecting all V vertices with exactly V − 1 edges and minimal total edge weight. Solved greedily by Kruskal (edge-driven) or Prim (vertex-driven).

    Disjoint Set Union (DSU with Path Compression)

    dsu.cpp
    struct DSU {
    vector<int> parent, rank;
    DSU(int n) : parent(n), rank(n, 0) {
        iota(parent.begin(), parent.end(), 0);
    }
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x]; // path compression
    }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        if (rank[a] < rank[b]) swap(a, b);
        parent[b] = a; // union by rank
        if (rank[a] == rank[b]) rank[a]++;
        return true;
    }
};

    Kruskal's Algorithm

    kruskal.cpp
    int kruskalMST(int n, vector<array<int,3>>& edges) {
    // {weight, u, v}
    sort(edges.begin(), edges.end());
    DSU dsu(n);
    int total = 0, edgesCount = 0;
    for (auto& [w, u, v] : edges) {
        if (dsu.unite(u, v)) {
            total += w;
            if (++edgesCount == n - 1) break;
        }
    }
    return total;
}

    Bridges, Articulation Points & Tarjan's Low-Link

    A bridge is an edge whose deletion increases the number of connected components. An articulation point (cut vertex) is a node whose deletion disconnects the graph. Tarjan's algorithm finds all bridges and cut vertices in a single DFS pass O(V + E) using discovery and low-link numbers.

    Tarjan's Low-Link Formula

    disc[u]: The step counter at which vertex u was first visited in DFS.
    low[u]: The lowest discovery time reachable from u's subtree via at most one back-edge.

    Bridge Condition: Edge u – v is a bridge if and only if low[v] > disc[u] (meaning v has no back-edge to u or u's ancestors).
    Articulation Point Condition: Node u is a cut vertex if low[v] ≥ disc[u] (non-root) or root with ≥ 2 DFS children.

    tarjan_bridges.cpp
    void dfsBridges(int u, int p, vector<vector<int>>& adj, vector<int>& disc, vector<int>& low, int& timer, vector<pair<int,int>>& bridges) {
    disc[u] = low[u] = ++timer;
    for (int v : adj[u]) {
        if (v == p) continue; // don't walk straight back to parent
        if (disc[v]) {
            low[u] = min(low[u], disc[v]); // Back-edge
        } else {
            dfsBridges(v, u, adj, disc, low, timer, bridges);
            low[u] = min(low[u], low[v]); // Tree edge
            if (low[v] > disc[u]) {
                bridges.push_back({u, v}); // Bridge discovered!
            }
        }
    }
}

    5-Step Systematic Decision Flowchart

    Step 1. Is the graph directed (dependencies, one-way paths) or undirected (bidirectional connections)?
    Directed → Topological Sort, 3-Color Cycle Detection, SCCs. Undirected → Components, Bridges, MSTs, Bipartite.
    Step 2. Are edge weights uniform, 0/1, non-negative, or negative?
    Uniform 1 → BFS. Weights 0 or 1 → 0-1 BFS. Non-negative → Dijkstra. Negative → Bellman-Ford.
    Step 3. Are you seeking single-source shortest path or all-pairs shortest path?
    Single-source → Dijkstra / Bellman-Ford. All-pairs with small V → Floyd-Warshall.
    Step 4. Are you connecting everything together as cheaply as possible?
    Yes → Kruskal / Prim MST (never confuse with shortest path!).
    Step 5. Does the graph structure change dynamically with edge additions?
    Yes → DSU (Disjoint Set Union).
