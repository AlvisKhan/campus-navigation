★ Logistic Regression

→ Supervised Classifier
→ Predict the categorical variables   $v_k$ → local induced field
$$z = \sum_{i=1}^{n} w_i x_i + b$$ $$\hat{y} = \phi(z) = \frac{1}{1+e^{-z}}, \quad \hat{y}\in[0,1]$$ $$P(y=1|x) = \phi(z) \geq 0.5$$ $$P(y=0|x) = \phi(z) < 0.5$$

Odds

$$\frac{1}{1-P} = \frac{P(y=1|x)}{1-P(y=1|x)}$$
$$\ln\left(\frac{P}{1-P}\right) = z$$ $$\Rightarrow \frac{P}{1-P} = e^{z}$$ $$\Rightarrow P = (1-P)e^{z}$$ $$\Rightarrow P(1+e^{z}) = e^{z}$$ $$\Rightarrow P = \frac{e^{z}}{e^{z}+1}$$ $$\Rightarrow P = \frac{1}{1+e^{-z}}$$
$$P(y=1|x) = \frac{1}{1+e^{-z}}$$
