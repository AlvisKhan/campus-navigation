1. Project Overview & Problem Solved

National Institute of Technology Silchar (NITS) spans over 625 acres with 50+ department buildings, 10+ student hostels, sports grounds, administrative offices, and lakes.

🔴 The Real-World Problem

Standard navigation apps like Google Maps lack verified internal pedestrian pathways, accurate hostel entrance locations, and department shortcuts. Freshers and visitors get lost during admissions and early semesters.

🟢 Our Technical Solution

A responsive web app with 54 physically verified GPS nodes, live pedestrian routing via OSRM, a 360° rotating compass HUD, a 2-stage GPS fallback engine for poor indoor fixes, and a Freshers survival guide with 24/7 emergency contacts.

4. Great-Circle Distance via Haversine Formula

Why standard Pythagoras distance fails on maps, and how the Haversine formula calculates exact straight-line meters on Earth.

Figure 2: Great-Circle Spherical Trigonometry between GPS coordinates
src/utils/geoUtils.js 
export function calculateDistance(lat1, lon1, lat2, lon2) {
  if (!lat1 || !lon1 || !lat2 || !lon2) return null;

  const R = 6371e3; // Earth radius in meters
  const toRad = (deg) => (deg * Math.PI) / 180;

  const dLat = toRad(lat2 - lat1);
  const dLon = toRad(lon2 - lon1);

  const a =
    Math.sin(dLat / 2) * Math.sin(dLat / 2) +
    Math.cos(toRad(lat1)) * Math.cos(toRad(lat2)) *
    Math.sin(dLon / 2) * Math.sin(dLon / 2);

  const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
  return Math.round(R * c); // Distance in meters
}
💡 Key Interview Takeaway: Euclidean distance assumes a flat 2D plane. On Earth, lines of longitude converge at the poles (1° lon = $111 \cdot \cos(\text{lat})\text{ km}$). The Haversine formula handles spherical curvature without numerical precision loss.

5. Forward Azimuth Bearing (Compass Direction)

How we calculate the exact directional heading vector from the user's current GPS location to the target building (e.g. 284° WNW).

Figure 3: Spherical bearing formula mapped to a 16-point cardinal compass dial
src/utils/geoUtils.js 
export function calculateBearing(lat1, lon1, lat2, lon2) {
  const toRad = (deg) => (deg * Math.PI) / 180;
  const toDeg = (rad) => (rad * 180) / Math.PI;

  const y = Math.sin(toRad(lon2 - lon1)) * Math.cos(toRad(lat2));
  const x =
    Math.cos(toRad(lat1)) * Math.sin(toRad(lat2)) -
    Math.sin(toRad(lat1)) * Math.cos(toRad(lat2)) * Math.cos(toRad(lon2 - lon1));

  let brng = (toDeg(Math.atan2(y, x)) + 360) % 360;
  const cardinals = ["N", "NNE", "NE", "ENE", "E", "ESE", "SE", "SSE", 
                     "S", "SSW", "SW", "WSW", "W", "WNW", "NW", "NNW"];
  const cardinalIndex = Math.round(brng / 22.5) % 16;

  return `${Math.round(brng)}° ${cardinals[cardinalIndex]}`;
}

7. OSRM Pathfinding & Google Maps Handoff

How pedestrian route coordinates are computed, transformed, and seamlessly handed off to native mobile apps.

1. Client-Side OSRM Polyline Flow
  1. User selects target (e.g. Central Library).
  2. App requests OSRM driving/walking service endpoint with origin and destination lon/lat.
  3. OSRM returns GeoJSON coordinates [[lon1, lat1], [lon2, lat2]...].
  4. App maps coordinates to Leaflet format [[lat1, lon1], [lat2, lon2]...].
  5. Renders SVG Polyline and calls map.fitBounds().
2. Google Maps Universal Handoff

When users are actively walking across campus, holding a browser map is less convenient than turn-by-turn voice directions.

https://www.google.com/maps/dir/?api=1&origin={lat},{lng}&destination={lat},{lng}&travelmode=walking

8. Top 10 High-Yield Interview Questions & Answers

Click each question to view the comprehensive model answer:

Q1 Why Leaflet over Google Maps JavaScript API?
▼

Answer: Three main reasons:

  1. Zero Cost & Rate Limiting: Google Maps JS API requires billing accounts ($7/1,000 requests). Leaflet is open-source and tile-agnostic (OpenStreetMap / Esri Satellite are completely free).
  2. Canvas & Marker Control: Leaflet makes it trivial to render custom CSS/SVG radar beacon markers and rotate the map canvas via leaflet-rotate.
  3. Lightweight Bundle: Leaflet is ~40KB gzipped compared to Google's heavy 150KB+ script injection. We still provide Google Maps turn-by-turn navigation via 1-click universal URL handoff.
Q2 Explain why Euclidean distance fails for GPS coordinates.
▼

Answer: Euclidean distance ($\sqrt{\Delta x^2 + \Delta y^2}$) assumes a flat Cartesian plane. Because Earth is spherical, longitude lines converge at the poles. One degree of longitude equals 111 km at the equator, but shrinks to $111 \times \cos(\text{latitude})\text{ km}$ elsewhere. The Haversine formula solves this by calculating the great-circle arc length on a sphere with mean radius $R = 6,371\text{ km}$, preventing distortion.

Q3 How does your two-stage Geolocation Fallback work?
▼

Answer: Mobile GPS with enableHighAccuracy: true often fails indoors. We wrap navigator.geolocation in a Promise that first requests a satellite fix with a 25s timeout. If it encounters POSITION_UNAVAILABLE (Code 2) or TIMEOUT (Code 3), it immediately invokes a fallback request with enableHighAccuracy: false (using Wi-Fi / cell tower triangulation). This prevents indefinite spinners and increases location success rates from ~55% to over 98%.

Q4 How does the compass rotation feature work?
▼

Answer: We extended Leaflet using leaflet-rotate, enabling two-finger touch gestures and shift+drag rotation. In CompassHudControl, a React hook listens to the map's rotate event, reads map.getBearing(), normalizes the angle between 0°–360°, and calculates the 16-point cardinal direction. The compass needle dial is transformed inversely (transform: rotate(-bearing deg)) so the red needle continuously points to True North.

Q5 How is client-side SPA routing handled without React Router?
▼

Answer: We built a lightweight router using the browser's native History API. A currentPath state tracks window.location.pathname, while a popstate listener synchronizes browser back/forward buttons. Calling navigateTo(path) runs window.history.pushState(null, "", path) and triggers a clean re-render without page refreshes or external bundle weight.

Q6 How do you optimize search across 54+ locations?
▼

Answer: Each location in locations.js contains a name, category, description, and an array of common student aliases (e.g., "BH1", "New Admin", "CCC"). When the user queries, the search bar checks all 4 fields simultaneously using case-insensitive substring matching. If GPS is locked, it computes real-time straight-line distances to each match and presents them sorted.

Q7 How did you fix the Leaflet canvas re-rendering glitch?
▼

Answer: Leaflet calculates tile grids based on container pixel dimensions at initialization. When switching SPA views or rotating mobile devices, the canvas dimensions change before Leaflet recalculates. We built a MapViewController sub-component inside <MapContainer> that hooks into useMap() and automatically triggers map.invalidateSize() and map.fitBounds() whenever coordinates or routes change.

Q8 How would you support indoor floor-by-floor navigation?
▼

Answer: We would store geo-referenced floor plan SVGs rendered as Leaflet ImageOverlays with a floor switcher. Corridors, stairwells, and rooms would be modeled as a weighted 3D graph $G=(V, E, W)$, using client-side A* pathfinding with stair penalty weights. User indoor position would be triangulated via Bluetooth Low Energy (BLE) beacons or Wi-Fi RTT.

Q9 How is mobile screen real estate optimized during navigation?
▼

Answer: On small screens, large destination cards block the map view. We designed an auto-collapsing Active Navigation HUD: as soon as a route is generated, the large card is automatically dismissed, leaving a compact 48px glassmorphism pill with distance, ETA, and a Google Maps handoff, leaving 90%+ of the viewport dedicated to the map.

Q10 How does the Freshers Companion complement the map?
▼

Answer: The navigation app addresses physical orientation, while the Freshers Companion addresses academic and emergency orientation. It indexes 24/7 campus ambulance & medical contacts, local transport numbers, 1st-year Google Drive study materials, and senior tips, acting as an all-in-one portal for the institute.
